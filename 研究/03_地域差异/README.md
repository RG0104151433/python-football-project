# 第三问：不同地理背景和主客地域关系下，主场表现有何差异？

2026-10-26，当前结构见R20261026-05，承接R20261026-02/03/04。**用户已确认当前只用地理区域作为新增分类依据。** 本页完成分析主线和逐步准备要求；具体分类版本、比较目录、参考方案和数学依据仍需随后讨论。地区表、分析脚本、地区结果和第四问正式检验尚未生成。

## 先读这一段

本题沿着一条线展开：**先看不同主队地区的实际表现，再看同一主队地区面对不同地域对手的表现，随后向洲内细分；在明确各自比较对象后，比较直接结果与统一年代、赛事构成后的结果。** 最后说明哪些差别尚可能与球队实力、赛程选择等有关，把可靠性交给第四问、实力交给第五问。

这里只新增地理分类。年代、赛事继续沿用前两问，作为理解赛程构成的已有信息。经济、文化、足球强弱、气候、海拔、距离和时差不另建分组或采集指标；足联仅保留背景说明，完整历史足联表不再是第三问开工条件。地理分类有明确关联背景，但不保证组内同质，也不能证明气候、旅途等具体原因。

## 1. 当前范围：哪些已确认，哪些还待确定

**已确认的边界：** 1980—2024、现有合格非中立场母样本24,917场；比分含加时、不含点球大战；平局包含在主胜率分母中。117场会员采用决定不变。以比赛为默认计数单位，一场只记一次主队表现，不能解释为每个国家获得同等权重。

**本轮新增确认：** 以地理区域为当前主线；洲内地理细分和双方地域关系属于题内组成部分，经济或社会指标不进入当前任务。历史足联对照由原建议的辅助分析降为可选背景，不要求首版计算同/跨足联结果。

**还需在数学与实施讨论中确定：** 地理标准及固定版本、历史实体处理、最终细区层次、少量主要差值、共同参考、支持不足的目标如何报告，以及正式脚本和输出契约。本页提出准备方案，不将这些建议写成用户已逐项批准。

## 2. 三个连续的研究目标

### A. 主队地理背景：不同地区的主场赛程表现怎样？

先分别展示各主队大区的比赛数、胜平负、主胜率、球队数，以及年代、赛事和客队来源构成。它描述“这批比赛里各地区主队表现怎样”，还不是“换个地区举办就会改变多少胜率”。

**提前准备：** 为母样本里的主队建立可追踪的大区归属；把比分、年代、赛事标签通过比赛ID接回；统计各队贡献的场数，识别某组是否主要由少数球队支撑。客队地理未知不自动排除此目标，只在对手构成中保留未知类别。比较地区率时不得拿“某地区”与包含它自身的全球率当独立两组；全球率可以作描述参照，正式差值另定。

### B. 双方地域关系：同一主队背景下，面对不同来源对手怎样？

在A的基础上保留客队归属，区分候选关系：同细区、同大区但不同细区、不同大区。先在同一主队大区内展示关系率；若覆盖允许，可进一步在同一主队细区内比较。不能只把全球同区和跨区比赛混合比较后认定为地域作用。

**提前准备：** 双方大区、细区及其来源；主队大区→客队大区的场数分布；每种关系中的具体主队、客队、年代和赛事构成。关系类别本身可能对调主客后不变，但“谁主场、在哪个主队背景下”必须保留。例如甲区主队对乙区与乙区主队对甲区分开记录，不把它们汇总为一个无方向对阵格。

关系三分类不要求穷举全部细区对阵。候选主差值是固定主队背景内“跨大区减同细区”，第三类辅助展示；采用哪些背景、哪些差值，要先看场数和研究意义，再固定目录，不按胜率挑。

### C. 洲内细分：大区平均是否遮住了内部不同的情况？

回到A，把同一大区内互不重叠的细区放到一起观察；再结合B说明这些细区面对的对手是否不同。例如北非与撒哈拉以南、亚洲次区域、欧洲地理分区可作为候选，但不能把“足球强国”“中东欧”“亚洲国家”当同一层级的互斥分组。

**提前准备：** 一份明确的分区层级表，说明每个细区属于哪个大区、是否为其他组的合并；细区×年代×赛事的场数、球队数、对手构成及每队占比。先给覆盖总览，再选择少量有背景依据且可比较的洲内对照。其他组即使不作主要对比也保留覆盖记录，不能隐藏无结果或不利结果。

A→B→C分别回答背景、关系和内部差异，同一场可用于三个目标，但不是三份独立证据。第三问不新增滚动窗口或展开全部地区两两检验。

## 3. 地理及其他因素在主线中的位置

### 3.1 地理层次：当前唯一新增分类

建议以固定版本的[联合国M49](https://unstats.un.org/unsd/methodology/m49/)作为外部依据，保存其原始代码和层级，再明确本项目实际使用的大区/细区。它是统计分组，不是足球或气候同质性的保证；具体版本尚未冻结。

**必须先解决层级不齐：** M49存在中间分组，例如撒哈拉以南之下还有东/中/南/西非，拉美和加勒比之下也有更细分区。不能把父组和其子组并列相加。拟议做法是保留原始层级，以互不重叠的细区作统一基础；北非/撒哈拉以南等更粗展示由已定义细区汇总。美洲的大区与北美、中美、加勒比、南美细分关系须明确，不能直接照搬两个足联边界。

准备时记录下载/访问日期、原始标准版本、代码、中文展示名、父子关系、合并规则、例外和来源。保存一份实际可用的来源快照及指纹；网页链接不是已完成归属表。

### 3.2 球队地域与比赛地点分开

主分析按球队代表实体的地理归属分类；既有country/city是比赛举办地，不能直接当主队或客队归属。非中立标记继续沿用现有规则，不以新地域表自动重判主场。来源名称与实际实体的对应需检查，但不重新打开已经采纳的会员资格。

建议采用固定分类框架，将同一代表实体在其有效时期映射到该框架，而不是每年跟随足联变化；这只是可比较的统计标签，不宣称它就是当年的官方地域分类。历史联合代表队、跨区实体、名称沿革和英国各足协须逐项说明：可唯一归到大区但细区不明确时，仅保留大区；跨大区且无单一合理归属时，标多区/未定，不按首都或今天的继承国猜测。不得把历史队拆成多场或合并球队ID。

### 3.3 经济、实力和具体环境因素的位置

- **经济与社会因素：当前不进入计算主线，也不采集。** 只有未来另立具体问题、确认指标和收益后才考虑；不在结果解释中把经济当成已经证明的原因。
- **足球实力：保留明确的解释缺口和第五问接口。** 地区差可能来自双方实力、同一地区内不同球队出场比例，当前不能消除。保留双方ID、日期、逐场分组和目标定义，便于第五问用赛前信息回访，不需现在算评级或选“强国组”。
- **气候、海拔、路程和时差：只列为尚未测量的可能机制。** 同区不必近、跨区不必远，国家队球员出发地也不等于国家所在地。当前不准备机场、球员驻地或气象数据，不能把地理关系换写成旅行效应。
- **足联：背景说明和未来可选对照。** 当前不新增历史归属数据任务，不把同地理区等同同足联。不完整的足联信息不影响纯地理分析。今后若做组织对照，应另外明确来源和历史有效期。

## 5. 逐步实施前，需要准备到什么程度

下列是待完成任务及验收要求，不是已生成的新文件。正式脚本设计时再确定文件名；现阶段不创建空表冒充成果。

### 第一步：固定分类字典与实体归属

**新增准备。** 先保存分类标准快照和层级表，再对上述球队清单填写大区、细区、适用时期、来源、归属理由、日期精度、已确认/部分明确/未知/冲突状态。区分来源给出的实体事实与我们采用的统计归类；历史例外单列决定，不能伪造官方逐年标签。

**通过条件。** 每个出现过的球队都有明确状态，未知也必须有记录；同一球队同一天在同一分类版本下不能有重叠有效规则。已知细区必须属于已知大区；只做改名不随意改地理；一个队可有多段时间规则，但每场最多匹配一段。无法定唯一归属保留局部可用信息，不强求全部有值才进入后续讨论。

### 第二步：按目标登记样本去向

**已有可复用。** 母样本身份、比赛ID、年代和赛事口径沿用前两问。

**新增准备。** 每场分别标A（主队大区）、B（双方关系）、C（主队细区）能否使用及原因，附实际匹配的规则ID和分类版本。A可纳入客队未知的比赛，C可纳入只有主队细区明确的比赛；B若双方大区已知且不同，可确定跨大区，即使某方细区未知。双方同大区但细区不足时，关系记未知，不硬填为同/不同细区。

**通过条件。** 各目标纳入、未知和不适用加总回母样本；每目标内一场至多一次。A/B/C样本若不同，分别报告差额及年代/赛事分布。比较A与C或比较前后差时，核对是否同批比赛；如另做共同子集对照，登记为新目标，不把样本变动混成细分或调整带来的改变。

### 第三步：只按场数检查覆盖，固定比较目录

**新增准备。** 在查看地区胜率之前，列主队大区/细区×年代×赛事的场数、主客球队数、主要球队的出场占比；再列主队背景×关系×年代×赛事，以及主队→客队地区场数。报告未知和缺组，区分“根本没有此类赛程”与“归属没查清”。

**通过条件。** A/B/C拟报告的范围、方向和主要/辅助身份有明确记录；不为了胜率好看新增地区或换基准。场数小可以描述，不凭任意30/100场保证可靠性。缺关键支持的目标标不可比较或缩小已说明的用途；具体预警及展示规则在解释结果前确定。候选洲内对照因覆盖无法做，也保留原因，不无限取证。

### 第四步：建立直接统计的解释基线

**已有可复用。** 胜平负判定、主胜率分母、单位和整数对账方式沿用前两问。

**新增准备。** 为A地区、B固定主队背景内的关系、C洲内细区分别准备场数、胜/平/负数、主胜率、主客球队数、年代/赛事/对手构成和每队出场贡献。共同展示组内率与分母，不仅列地区排名；不把某地胜场占全球胜场比例当当地胜率。

**通过条件。** 胜平负之和等于各组分母，互斥组加总与对应目标样本相符；大区与细区加总只在同一可用样本上核对。没有发现差异、方向混合或无法比较，都是可接受的结果。

### 第五步：准备共同构成比较，但不预先宣称全部可比

**已有可复用。** 五年代×两类赛事的定义和母样本十格计数。它们不是直接可套到所有新目标的最终方案。

**需要分别确定的准备。** A的大区对照可讨论母样本十格作为共同参考；B的同一主队背景内关系对照可讨论该背景内合并赛程参考；C的洲内细区对照可讨论该大区内合并赛程参考。每个候选方案都要写清参考来自哪批比赛、未知如何处理、代表什么人群、是否固定，先查各组能否覆盖所有正权重层，再决定采用。不同参考所得率不能不加说明混作一张统一排名。

**两处必须避免的逻辑错误。** 第一，不能要求同细区和跨大区比赛还拥有完全相同的客队细区构成：关系本来就由双方来源定义，部分组合结构上不可能重合。第二，即使固定主队大区，不同关系中的主队细区/具体球队也可能不同。应保留这些构成供解释，必要的进一步调整另定可行目标；不承诺把主客构成“全部统一”，也不以无限细分换取表面公平。

**通过条件。** 每个调整目标只有一套明确、共同的参考与适用样本；正权重层缺组则该目标不可估，不填零、不各组静默删格重归一。若考虑有支持子集或粗化分类，先另立目标并记录理由。只在同批比赛和对应目标下解释直接—调整变化；这一步数学原理和最终参考留下一轮讨论。

### 第六步：结果解释与计算验收

**新增准备。** 对每项比较同时保留直接值、调整值、分母、参考、方向、不可算原因和限制，准备能够从整数场次重建的计算示例及独立复算路线。核对主客交换、未知细区但已知大区、同大区关系未知、空格、历史时间边界和重叠规则等案例。

**通过条件。** 逐场归属、样本加总、层级汇总、权重、胜平负、差值单位和版本一致；发生冲突要显式报出，不能默默选一条规则。结果变化只说明比较指标对构成的反应，不说年代/赛事或地域造成了多少胜率。当前不报告显著、稳定、因果或预测增益。

### 第七步：第四问与第五问交接

**提前保留。** 各目标逐场ID、主客身份与日期、真实赛果、原始/调整目标、层计数和参考、分类版本及源证据、纳入去向、缺组状态；使后续能重建各场对目标的贡献，而非只剩平均数。前三问共享比赛/球队/年份及第一、二问已有窗口归属一并保留。

**第四问准备。** 以实际目标目录确定比较族、相关结构、敏感性范围及模拟验收；分类边界未知与赛果不确定分开处理。只采用地理后，不把经济/足联缺表列为检验阻塞。详细准备要求见[共同任务](../../文档/05_团队协作/分工与交付/04_两题共同可靠性与敏感性.md#第三问开始前后需预先准备的内容r20261026-04)。正式方法、区间与新增敏感性不塞进第三问描述脚本。

**第五问接口。** 沿用原赛果与分组，未来在赛前实力可用时回访相同目标；若评级覆盖缩小，另报共同子集。当前不要求先完成评级，第四问区间也不替代实力控制。

### 描述阶段最终应交付什么

在上述准备和后续原理讨论完成后，第三问至少应留下：分类来源与规则、逐目标样本去向/覆盖、A/B/C直接表现、可估目标的共同构成结果与差值、不可估及限制清单、计算复核和第四/第五问接口。它们是未来交付要求，当前没有这些结果表。

## 6. 所需背景信息与当前明确不准备的资料
