# 第三问：地区与主客地域关系下的主场表现

**中文** | [English](README.en.md)


本页为2026-11-12核对后的当前入口；采用样本和结论未变，推导及旧阶段记录见文末历史说明。

## 研究问题

不同主队地区、洲内分区以及对手来源下，主队表现有什么差异？

## 分析方法

先固定双角色分组，再计算分区总体和有方向主客组合；以共同年代×赛事构成比较可支持的目标。完整覆盖四项地区研究，不只选择最高与最低组。

## 主要结论

已产出29项差值与155个主客组合；24项全期调整差可算，153组合有比赛、71组合支持完整调整。第四问24项中6项模型条件范围在零一侧，其余18项跨零；结果体现对阵构成与地域差异，不能据此排纯主场能力榜。

## 解释限制

土耳其计欧洲/南欧、伊朗计西亚、澳大利亚计亚洲/东南亚，是明确登记的项目约定。非洲三组，大洋洲不分区；缺层保持不可估，不填零。
