## 1. 本次究竟计算了什么

原24,917场全部保留，仍只研究1980—2024合资格非中立比赛，平局计入分母。原始资料、117场采纳、前三问描述和第四问区间均未覆盖。

程序比较9个事前确定的模型：只含背景、含分区的背景、只含实力、实力与大区共同、实力与分区共同、分赛事的实力联系、少量对手关系，以及两个评分分布近似对照。M3“实力与分区共同”是预定主模型，没有因为另一个模型损失更小就事后换主模型。

实力差连续进入主胜概率，并对其赛前正态＋Poisson跳变分布积分。主客双方地理都加入；欧洲四、亚洲五、非洲三、美洲四分区及大洋洲整体不变。土耳其欧洲/南欧、伊朗西亚、澳大利亚亚洲/东南亚约定沿用；未知作为类别保留，分区与所属大区采用受约束编码，避免重复计算。

第四问目录实际有32项主要对比：2年代、1赛事、29地域。其中原分层27项可算、5项缺层，本次纠正了设计中“27项CORE”的简写错误。全部32项映射都保留，各有全参考与辅助参考，合计268条模型/目标结果、64条同参考实力前后比较和128条敏感性比较。这不是为原155个有方向对阵各拟合一个独立参数，也没有重新计算旧第四问区间。

## 2. 现有结果能说明什么

在**同一个新参考、同一背景编码**下，主胜二元损失从无实力的0.666607降到含实力的0.565474；主胜/非主胜样本内正确率约58.56%→69.61%。这表明历史强弱信息与这批赛果有很强联系，但这是回顾性拟合，不能当作提前预测未来比赛的成绩，也不能与旧评分器三结果损失直接比较。

几项容易理解的全参考对比（单位均为百分点）：

- 亚洲主队对洲外与同分区对手的差：不含实力约−15.01，加入后约−4.06。
- 欧洲对应差：约+15.31→+6.19。
- 北非相对其余撒哈拉以南：约+21.97→+8.40。
- 南美相对美洲其他研究分区：约+17.87→+7.74。
- 友谊赛相对其他赛事：约−3.86→−3.50，纳入实力后这项差没有同样大幅缩小。
- 2010年代、2020—2024相对1980年代，在新共同模型中分别约−2.56、−4.57；同背景但不含实力时约−0.68、−0.82。

有研究价值的线索是：**一些看似很大的地域差异，与双方强弱和对阵构成有明显联系；赛事差和年代差未必以相同方式改变。** 这给后续研究提供方向，尚不是因果分解、稳定方向或显著性结论。旧第一问只统一赛事比例，新模型还统一地理、对手和实力条件，估计对象不同，不能直接称旧结论被推翻，也不能报“实力解释了多少百分比”。

有限关系对照允许友谊赛与其他赛事的实力斜率不同，拟合有所改善。这是需要进一步验证的候选联系，不代表评分器友谊赛学习系数0.65已被估成新的值；两个系数所在层次和含义不同。

## 3. 必须与数字一起讲的支持限制

32个全参考比较都出现不同程度的资料外推。程序另外保存双方情景都有非空单元、评分位于已观察范围内的辅助参考，不将它冒充原全样本。

例如，辅助参考中，年代两项分别保留21,196、19,930行，赛事保留21,581行；亚洲对手关系471行、欧洲244行、南美仅8行。它们不是新增比赛数，而是用于比较的参考行数。南美这项尤其不能作稳固全期结论；原5项缺层仍按原状态记录。

辅助参考也不等于已经证明充分的共同支持：目前检查的是预定粗单元及评分极值，不是所有连续因素或未观察条件。主客地区、研究分区的单独系数也不能叫作“该地区的纯主场优势”。主样本全是非中立比赛，本环节没有识别纯场地因果效应。

## 5. 文件、格式和运行方式

当前全量结果目录为[joint-analysis-55371e4d4aa3d2060190](../../outputs/tables/strength_joint/joint-analysis-55371e4d4aa3d2060190/manifest.json)：

- `model_metrics.csv`、`models.json`、`coefficients.csv`：模型、参数与数值诊断。
- `joint_predictions.csv`：同24,917场、各模型拟合概率、评分信息截止与回顾性拟合标记。
- `contrasts.csv`、`strength_changes.csv`、`support.csv`：新参考两情景、百分点差、实力前后变化与支持限制。
- `sensitivity.csv`、`sensitivity_models.json`：4变体、128对比，明确变动范围。
- `validation.json`、`manifest.json`、`source_snapshot.zip`、`data_dictionary.md`：实际验证、输入/配置/环境/源码与输出指纹。
- `display_data.json`：展示取数。正式材料包另有两组PNG/SVG、规范模拟输入、测试与核验副本；不是最终HTML或论文正文。

CSV统一UTF-8 BOM、LF和固定小数；没有经验收的区间留空，状态为`INFERENCE_NOT_ADMITTED`。输入错版、当前结果泄漏、分布参数缺失、矩阵不满秩、无共同支持、优化失败和数值失败分别报错，不输出一个不明原因的空表。失败不得覆盖旧通过版本。

在仓库根目录运行：

```powershell
.\.venv\Scripts\python.exe scripts/analyze_strength_joint.py --stage analysis
.\.venv\Scripts\python.exe scripts/audit_strength_joint.py
```

```powershell
.\.venv\Scripts\python.exe scripts/analyze_strength_joint.py --stage global-feedback
```

`--stage all`依次执行以上两阶段。实际目录以控制台和`outputs/logs/strength_joint/analysis_pointer.json`为准，代码或环境变化会生成新身份；不能手动改目录名冒充旧版。`--skip-sensitivity`仅供开发或核心复现，其产物明确另列，不能替换完整敏感性主入口。
