# 第五问：赛前实力评价与调整

2026-10-28，R20261028-06。**当前是目标与定位讨论稿，具体研究目标、比较范围、算法和验收方案尚未最终确定；没有生成评级、调整结果或预测。**

## 1. 怎样理解前三问的验证情况

不能把现状合并成“前三问不可靠，等加入实力就能修好”。当前至少有三种不同判断。

**计算与描述：** 在已接受的数据、分类、分母和参考口径下，原比例、率差与构成调整已经复算。它们是对这批比赛的真实统计描述；不代表档案无遗漏或所有历史事实均已独立认证。

**差异的证据强度：** 第四问为原目标生成工作模型条件范围。所检验的年代主差、全期赛事差、近期直接差及36窗范围跨零，尚不能确认相应方向；第三问有6项预定差值在模型条件下保留方向支持。跨零不证明没有差异，范围在零的一侧也不等于真实世界无条件保证。部分范围很宽，说明在允许的共同波动下精度不足。

**差异如何解释：** 目前没有把每场双方赛前实力纳入可比条件。某组主队赢得多，可能与主队更强、对手更弱或对阵选择不同有关。即使某项差异方向有条件证据，也不能直接归因于主场、地域或赛事本身。

第五问主要补充解释与条件比较这一层，同时需要检验新分析自己的不确定性。引入实力不会自动缩窄旧区间、自动提高可靠性，或让原来不明确的差异变得显著。前三问和第四问保留各自成立的描述与限定结论，成果不等待第五问才能有意义。

第四问使用的球队均值项帮助处理均值、相关性和共同波动，没有生成逐场赛前实力，也没有替换原AY点统计量。因此，不把它称作已经完成第五问。

当前实际证据见[第四问结果与复现](../04_共同可靠性/第四步_运行结果与复现.md)，不是重新运行或改写第四问。

## 2. 建议的核心研究目标

**考虑双方赛前强弱和对阵实力构成后，年代、赛事和地域中的主队表现差异还剩多少？在明确可比的条件下，是否仍有值得研究的主场信号？**

这包含两个层次，需要在下一轮分别定义：

1. **实力调整后的组间差异。** 让不同年代、赛事或地域的比较不再主要由强队比例和对手强弱差异决定，再看主队表现的关联怎样变化。
2. **同等或相近实力下的主客表现。** 若要把结果正式称为“主场优势”，还须确定主队相对客队的比较指标、对照和模型条件，不能仅给一个调整后的主胜率便宣布识别了主场作用。

举一个纯说明例子：A组主胜率60%、B组50%，但A组更常由强队迎战弱队。原10个百分点的差异是明确的描述，未说明A组的主场作用更强。第五问要问，在对阵强弱构成相同或可比时，这个差异是否仍然存在。此处60%/50%不是项目实测值。

平局必须继续考虑。例如，纯说明情景中的主胜40%、平35%、客胜25%，主胜率虽低于50%，主队仍比客队更常获胜。因此，不能机械地用“主胜率超过50%”定义主场优势。具体采用主客胜率差、预期表现或其他指标，后续再讨论，不在本轮拍板。

## 3. 球队实力评估在本问中的位置

实力评估是后续比较的基础输入和基准，不是观测到的客观真值。它应帮助回答：这场比赛开始前，我们依据已有比赛记录，对双方强弱知道多少？

至少要区分主队实力、客队实力及双方差距，不能只说某支主队强不强。不同时代分数的可比性、历史少的球队和长期不比赛的球队也会影响这个尺度的含义。

它有三项作用：

- **帮助建立可比条件。** 比较类似强弱对阵下的表现，或让各组使用共同的对阵实力构成。
- **提供赛前表现基准。** 看主队表现相对于双方实力通常对应的表现，是否还包含额外关联。基准的表现指标需要明确，不能直接把Elo预期积分当作主胜概率。
- **给后续研究提供可复用输入。** 第六问可以研究历史信息保留多久，第七问考察地区间有效性，第八、九问再检验未来预测和增量价值。本轮不会提前声称这些用途已经验证。

实力评分本身要有基本质量证据，特别是按时间顺序的检查；不能按“哪个评级能让主场结果更明显”来挑方法。评分有误差时，调整后仍有残余差异，可能包含实力没有被刻画充分的部分。

还须检查评分与主场表现相互影响的风险：若评分直接包含预先设定的主场加分，不能又把该加分当作独立证据证明主场优势；即使采用不显式加分的评级，历史主客赛程也可能进入评分，不能宣称已经完全排除这一问题。

## 4. 整体打算：形成前后可对照的证据

拟议主线是：

**只用赛前已有历史评价双方 → 在可比样本和对阵条件下重新比较 → 衡量组差与主场信号的变化 → 报告新结论的不确定性和限制。**

具体实施尚未设计，但整体需要做到：

- 保留前三问的描述基线。若评级覆盖或历史不足使第五问样本改变，先在第五问共同样本上重算调整前基线，再比较调整后结果，避免把换样本的变化误记为实力调整作用。
- 同时考察对阵强弱与原来的年代/赛事/地域视角，不只制作一个国家队排行榜，也不按调整后的显著性临时选择主要目标。
- 给实力评估和后续比较分别设验收要求。新目标、样本、估计与不确定性方案不能直接套用第四问冻结的临界值；调整前后共用比赛，也不能默认两者误差独立。
- 只用本场开始前可用的信息。本场和未来赛果不进入本场赛前评分，参数选择与效果检验也要避免使用未来测试信息。
- 将评级历史范围与正式研究样本分开。生成1980年初的赛前实力可能涉及热身历史，当前1980—2024会员/样本采纳不自动覆盖更早时期；本轮不扩样本、不合并实体、不重新开启117场补证。

成果应包括：可追踪的赛前实力信息、评分质量证据、同一可比样本上的调整前后比较、新结果的精度和解释限制。评级是其中一部分，调整后的研究结论才是这一问的主要交付。

## 5. 不预设哪一种结果才算成功

- 调整后差异明显缩小：支持原描述与所用实力/对阵构成有关；不能直接写成“全部由实力造成”，更不能把缩小比例当因果贡献。
- 调整后差异仍存在、精度和检查也足够：说明仍有该实力刻度未能刻画的关联，值得进一步研究；不是自动发现了某个地理、文化或主场因果机制。
- 调整后仍不明确：如实报告证据不足，不能用“未显著”证明没有影响，也不通过继续调参追求想要的结论。

第五问是从现象描述走向更可比的解释性分析。未来是否能用于预测，还需后续独立的时间检验。
