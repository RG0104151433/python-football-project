# 第五问：加入赛前实力后，比赛背景还有多少信息？

**中文** | [English](README.en.md)


本页为2026-11-12核对后的当前入口；采用样本和结论未变，推导及旧阶段记录见文末历史说明。

## 研究问题

只用比赛开始前可得的历史判断双方实力，再考察年代、赛事和地区是否仍提供信息，以及预测是否改善。

## 分析方法

按日期先预测后学习，主客双方共同更新实力并保留不确定性；比较仅背景、仅实力与实力加背景，并对共同分析作敏感性和双路线验收。

## 主要结论

同一21,413场历史预测中，实力加背景相对仅背景的对数损失下降16.12%，相对仅实力下降0.42%；二元准确率70.01%。采用完整非线性A，30项获准模型条件参照，24项地域前后变化不准入。

## 解释限制

历史时间顺序预测不是新增盲测；二元成绩不是完整胜平负成绩。统计参照有模型条件，不能称54项目全部通过或背景存在因果作用。
