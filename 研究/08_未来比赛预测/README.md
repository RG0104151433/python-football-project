# 第八问：在比赛开始前保存真正的未来预测

**中文** | [English](README.en.md)


本页为2026-11-12核对后的当前入口；采用样本和结论未变，推导及旧阶段记录见文末历史说明。

## 研究问题

把历史研究用于2026年11月12—17日欧国联，并在赛前保留可追溯概率及拿不准的程度。

## 分析方法

将新赛果接入并更新实力，在统一截止时点生成两轮预测，分开共同二元主预测与原评分器辅助三分类，然后封存来源与结果。

## 主要结论

52场已封存：49场主预测、3场特殊场地主模型不外推；52场附辅助胜平负。49场中21场倾向主胜、28场非主胜，32场条件实力范围跨50%；这不是实际成绩。

## 解释限制

两轮均采用11月2日当时信息，第六轮未吸收尚未发生的第五轮结果。条件实力90%范围不是现实90%覆盖保证；本次课程研究不等待赛后检验。
