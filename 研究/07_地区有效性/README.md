## 1. 从前面的问题自然引出

第三问发现不同地区的主队胜率不同；第五问发现双方实力提供主要预测信息；第六问比较参考多久的历史，暂时保留原来的累计评分和累计预测规则。但一个办法在全部比赛上表现较好，不代表它在每个地区都好用：比赛多的地区可能掩盖比赛少的地区，总体平均还可能掩盖某些地方长期高估、另一些地方长期低估的问题。

因此，本问的主要问题是：**保持同一套办法不变，它在不同地区是否都能给出有用的主胜概率？哪些地区存在较明显的预测偏差，哪些地区目前还缺少足够证据？**

这里研究主胜与非主胜，不能将现有共同模型称为已经验收的完整胜平负预测器。研究中的“地区”先按主队所属地区组织，客队地区与双方关系用于辅助解释，不在开头同时铺开所有组合。

## 2. 研究目标与本问价值

本问要交付一张可解释的“方法适用情况清单”：各地区有多少比赛、概率判断表现如何、相对同场参照有无改善、是否总体高估/低估、结论覆盖什么范围。

三个实际目标：

1. 检查整体成绩是否遮住了某些地区的不足，而不是只再排一次名次。
2. 区分预测较差、系统偏差、比赛较难和资料不足等可能情况；资料不支持时保留不能判断，不强行选一种解释。
3. 为第八问未来比赛提供适用范围说明，为第九问明确值得改进的对象。本问先诊断，不一边为各地区调参数，一边拿相同成绩证明改进。

不同地区之间的平均扣分不能直接当“对哪个地区更懂”：强弱差距、平局比例、赛事构成、球队历史资料都会影响预测难度。即使与同场参照比较，也不能宣称所有赛程差别都已消除。

## 3. 与前面各问的联系和边界

- 第三问回答“哪里主队更容易赢”；本问回答“程序在这些比赛上判断得怎样”。高主胜率不等于容易预测，低主胜率也不等于方法失效。
- 第四问提供相关性、小样本和多个比较的风险意识；旧目标的统计范围不直接复制给新的地区预测指标。
- 第五问提供赛前评分、含背景的共同预测和历史年度预测；已有地域偏差只是本问的线索，不当作独立新发现。若复用第五问仅实力预测，必须先核对样本、输入评分、学习起点及预测协议兼容，不直接拼接数字。
- 第六问提供默认采用办法、同场比较和已知局限。继续积累历史不等于旧比赛恒定同权，也不证明它在每个地区最佳。
- 第八问才做赛前锁定的未来预测；第九问才比较有针对性的改进。本问已有历史检验不充当新盲测，也不证明对完全没有学习过的新地区可以迁移。

## 4. 综合实力与不确定性的六步推进（R20261101-13）

本节整合R11初稿与R12讨论，作为当前推进顺序。核心目标不变：评价同一含实力的办法在不同地区是否有用，并区分比赛难度、实力资料不足和评价证据不足。以下是规划，不是已完成的分析；样本、分层边界和统计实现仍须在相应运算前落实。

### 第一步：明确研究对象、比较对象和判断标准

先固定现有“实力＋背景＋实力不确定性”的累计默认，研究主胜与非主胜。建议主要比较2010—2024；主队地区为主线，南美按既有分区另辨识，客队地区/主客关系辅助解释。已有历史已被研究复用，不称新盲测。

主要参照优先复用“只看实力”的办法，先确认同场、同版实力信息和学习协议兼容；全局过去主胜比例仅作必要的常识检查。主要指标为裁剪对数损失，Brier和二元准确率辅助；同时检查高估/低估与概率分档是否符合实际。旧区间不直接继承。

在正式计算之前明确主要比较、统计目标、相关性和小样本处置；不等看完误差再决定什么算支持。结论允许没有改善或不能判断；未给定实际容忍差距时，不做等效认证。若参照不兼容，先说明最少补算需求，再规划脚本。

**交付：研究清单、指标/证据规则、参照兼容要求和范围说明。** 这一阶段回答“究竟要检验什么”，不是先给每个地区训练一个模型。

### 第二步：连接已有预测、实力分布和地区资料

优先使用已有逐场概率、真实赛果及赛前实力特征，连接主客地区、双方实力差、差值基础方差/跳变、历史场次及冷启动。保留双方协方差的影响；不能把两个球队方差随意相加，也不能直接把评分方差当概率区间。

逐场核对ID、日期、标签、来源和赛前截止，防止连接映射后重复计数或使用赛后信息。沿用土耳其欧洲/南欧、伊朗西亚、澳大利亚亚洲/东南亚等项目约定；南美不能用整个美洲019代码代替。未知或缺少字段单独登记。

现有9727场主队大区的只读覆盖为欧洲3322、亚洲2540、非洲2058、美洲1659、大洋洲148；还要查球队、年份与赛事集中程度，这些人数本身不保证可靠性。只有确认输入齐全，才开始地区表现运算。

**交付：同版逐场评价输入、数据字段说明与地区资料覆盖表。** 不重新清洗、建评分或重跑全部年度模型。

### 第三步：先计算各地区表现与概率偏差

每个地区都在同一批比赛上比较默认和参照：概率扣分有无改善，平均预测与实际主胜比例是否接近，二元判断猜对多少。按资料允许的少量预定概率档，检查“报约六成的比赛，实际是否约六成主胜”。

平均偏差接近零可能是高低估抵消，不能因此宣称每场都准；小地区不靠大量细分箱制造不稳定名次。地区原扣分和相对参照改善分别报告，不能只用原准确率跨地区排名。

**交付：地区表现表、偏差/校准说明和少量主图。** 此时得到的是历史表现，还不是地域原因或未来保证。

### 第四步：结合实力差与信息充分程度解释差异

重点区分两种情况：两队本来势均力敌，所以难猜；或者我们对实力知道得不够，所以判断缺少依据。利用已保留的实力差、评分不确定性、双方历史场次，检查地区较差的表现是否集中于这些情形。

采用少量按过去训练资料规则确定的分层；切点必须在看本轮分层误差前固定。必要时再看赛事、时期和主客地域关系，不一次铺开全部交叉格。对构成调整只使用各地区共同有资料的层，报告失去的范围；缺层不补假数据。联系不等于因果。

现有预测已整合实力不确定性，不再往概率或扣分中额外叠加“可信度权重”。完整积分与仅用均值的专项算法比较不默认加入；若确实需要，另分固定参数预测诊断和重新学习的算法比较。

**交付：差异集中在哪些比赛条件、哪些解释有证据、哪些仍未知。** 不在此步重新给各地区调参数。

### 第五步：检查结论稳定性和证据强度

沿用第一步预定的评价目标与可用统计方案，检查主要发现是否依赖单独某年、少数球队、少量低信息比赛或特殊构成。固定预测上的删年/子样本只是评价诊断，不冒充删年重训；同一比赛跨多张分组表也不是独立重复证据。

区分比赛偶然性、实力知识不足、有限样本/相关性及模型参数和假设的限制。当前实力分布积分并未传播全部模型误差，不能由此直接给地区95%保证。原第六问条件界的宽度和适用问题先检查，不能照搬后包装成已验证的新目标；只有确有必要且理论适配，才补最少计算。

不显著不等于同样有效。对每条发现记录“历史描述”“有条件支持”“目前不能判断”；程序失败另外记为未完成，不能混作有效负结果。主要比较以外的细分保留探索标记。

**交付：稳定性说明、每条结论的证据等级和允许表述。** 不重复全套回归或为显著性反复增加模拟。

### 第六步：形成地区和比赛条件的适用说明，完成交接

分别回答：哪些地区历史预测较有帮助，哪里存在高估/低估，问题是否集中在实力接近或资料少的比赛，哪里仍不能判断。不把某类比赛的不足直接归为整个地区无效，也不把总体较好写成每场可靠。

同步研究说明、论文/汇报支撑索引、同版取数与版本登记。第八问据此说明未来预测的适用边界；第九问再隔离选择与评价，尝试有针对性的改善。不能只挑容易预测的地区宣传准确率；没有明显地区差异也可按负结果收尾。

**交付：适用范围清单、可转述结论、材料索引与后续问题清单。** 本问的终点是诊断和证据说明，不是保证所有地区都通过。

## 6. 实力、不确定性与分地区统计之后的分析（R20261101-12，讨论补充）

**本问评价的默认已经包含实力因素及其实力评估不确定性，不是从地区胜率重新预测。** 代码`src/strength_joint/model.py`的Kernel/predict和既有M3模型使用主队减客队的实力分布，将基础方差、双方潜在跳变混合进入主胜概率，再和背景信息共同形成判断。第七问继续使用同一模型；仅实力方案是参照，不是把含实力和不含实力的概率再人为加权一次。

不能直接观测真实比赛中球队的真实实力，因而对真实比赛检验的是“这种实力信息是否有助于预测”，不是声称评分与真实实力误差已直接测出。模拟真值仅回答规定机制中的追踪问题。

### 6.1 怎样评价准确性

实际主胜记y=1，平局/客胜记y=0，模型概率为p。沿用裁剪对数损失为主指标，惩罚过度自信地判断错；Brier分数mean((p−y)²)作辅助；p≥0.5判断主胜的二元准确率仅作直观补充。预测60%的比赛不应因恰好一次没赢就判整个概率错误，要在一组类似预测中检查频率。

分地区报告平均预测减实际比例，表示整体高估/低估；如资料足够，再用少量事前固定概率档检查“报六成的比赛是否约六成主胜”。平均偏差接近零仍可能是不同比赛的高低估互相抵消。各地区与参照都需在同一批比赛配对比较，不能拿不同人群的原准确率高低代替方法增量。

### 6.2 三层不确定性不要混用

1. **比赛本身难猜。** 两队实力接近时，资料充分也可能只有约一半主胜机会。主胜/非主胜条件结果的方差为p(1−p)，它不是主胜概率的置信区间，也不是评分方差。
2. **我们对实力知道得不够。** 比赛少、久未比赛等会使赛前实力分布更宽；双方实力差的不确定性需保留双方协方差和跳变成分，不能只相加两个评分误差。默认模型已将这层整合进p。本问应保留这类字段用于诊断，而不是再把某个不确定性系数加到概率或最终扣分中。
3. **对地区表现结论有多大把握。** 地区比赛少、集中在少数球队/年份，平均分数会不稳定；日期与球队关联需在方法选择时考虑。这是第五步评价证据强弱的问题，不由某场p或评分方差直接给出。共同模型系数估计、模型假设失配还带来概率估计层面的不确定性，现有强弱分布积分不等于已完整传播这些误差。

数学上，固定已拟合参数及赛前信息，让Q表示由潜在实力引出的条件主胜概率，p=E(Q)。则

\[
\operatorname{Var}(Y)=E[Q(1-Q)]+\operatorname{Var}(Q)=p(1-p).
\]

因此，将已经整合实力后的p(1−p)再加一个Var(Q)，会重复计算。这一恒等式不认证模型正确，也不解决系数估计误差或未知现实的覆盖保证。未来如要输出概率区间，必须另定区间所针对的不确定性与合法计算方法，不把主胜概率和“可信度”合并成一个任意分数。

### 6.3 统计之后还需要做什么

在原六步内补充以下职责，不另扩展许多实验：

- 第二步连接同版赛前实力差及方差、双方历史场次/冷启动等字段，确保均在结果前可得，旧Q5初始化字段不能冒用为新政策验证。
- 第三步计算表现、同场参照差和校准；只报告地区平均排名还不够。
- 第四步检查差异是否来自比赛难度和资料不足：在全体过去训练资料上确定的少量实力差/评分不确定性分层内，查看地区表现；切点须在看本轮分层误差之前按规则固定，不以成绩最差的位置切箱。各区支持不足的层不补假数据，统一构成仅限共同支持范围，不作地域因果解释。
- 第五步检查时期/球队集中及分层结论是否稳定，评分不确定性与表现差的联系仅是诊断，不能直接认定其造成错误。不把分档多重比较全部升成主要验证。
- 第六步交付“地区＋比赛条件”的适用说明。例如历史信息少的场景证据较弱，与整个地区都无效是不同结论。只诊断、不在相同样本上随意修正。

是否专门检验“纳入实力不确定性是否改善预测”，属于另一个对照问题。必要时可另行规划：在保持其余参数和比赛固定时比较完整积分与只代入实力均值的概率；这只诊断预测阶段的计算影响。若要比较两种完整建模策略，必须各自仅用过去拟合再比较，不能把固定参数切换冒称完整算法验证。本轮不默认增加这项实验，尚未确定分层切点或新统计模型，也未运行新分析。
