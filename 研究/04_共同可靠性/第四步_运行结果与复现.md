## 2. 三问的结论现在应怎样讲

### 第一问：年代变化的方向证据仍不充分

统一赛事构成后，2010—2019减1980—1989仍是+0.5019个百分点，但模型条件范围为−61.6553至+62.6592个百分点；2020—2024减1980—1989仍是+1.8100个百分点，范围达到逻辑全范围−100至+100个百分点。

这些范围非常宽，不能支持明确的年代改善方向，也不表示真实变化必然有几十个百分点。它说明：在本次允许的长期共同波动下，单段历史不足以将两者精确分开。不能为了让结论更好看，改用独立比赛误差或缩小允许的共同波动。

描述敏感性还给出更具体的提醒：固定原参考、删除真正涉及对比的年份时，2010年代差在−0.2350至+1.0112个百分点间；删去1988年会变负。2020—2024差在+0.9054至+2.5595间，方向未变。固定参考下前者只有20个涉及年份、后者15个；不把其余不涉及年份记成稳定证据。

把参考随删年重算时，两项分别为−0.2502至+1.0146、+0.9832至+2.5868个百分点。第一问已有的年度等权与完整权重曲线继续保留；年度等权得到+0.6482、+2.1041个百分点，和当前同版来源一致。

**可用表述：** 调整赛事构成后的年代差较小，2010年代的描述方向对个别年份敏感；本次工作模型范围尚不能确认年代差方向。不要写“主场优势已随年代显著增强”，也不要写“已经证明年代没有作用”。

### 第二问：描述上的类型差仍在，稳定反转尚未得到支持

全期友谊赛减其他赛事的调整差为−2.8831个百分点，模型条件范围−7.2039至+1.4377；2020—2024直接差为+6.1563，范围−13.2717至+25.5842。两项分属CORE与AUX家族，不能合并成一份共同保证。

全期调整差在45次删年中保持负值：固定参考为−3.0739至−2.6794个百分点，重算参考为−3.3031至−2.6323。近期五次删年保持正值，范围+4.7459至+6.8648。这里描述方向一致，仍不能代替其模型条件区间跨零的事实。

共同球队交集有153个稳定ID，要求双方都在集合内后保留17,760场、移除7,157场。这个子人群中，全期调整差为−4.1080（固定原参考）或−4.5631（重算参考），说明参与球队与参考构成确实会影响数值；不能说它就是原总体的更准确答案，也未控制实力。

原36个十年窗口全部保留，它们的共同范围均跨零。窗口内年份改为等权的描述对照也已计算，但窗口数不是独立验证次数。五年直接差、十年调整曲线和全期差是不同对象，不能据线条穿零宣布已经定位“反转年”。

**可用表述：** 全期与近期的描述方向不同，在已列删年对照中分别保持方向；当前模型条件下仍缺乏明确的全期方向和稳定反转证据。

本轮最低清单中的共同球队/逐队检查针对全期主目标，没有另为近期定义球队和年度参考专项目标；不据此声称近期变化已经通过所有维度的稳定性验收。正式变点、其他窗口宽度和此类补充目标均没有运行。

### 第三问：六项原定差值在当前模型条件下保留方向支持

CORE的27个可算目标中，6项范围在零的一侧，均来自第三问；第三问另18项可算调整差跨零，5项调整差仍因缺层不可估。这里列出的6项是完整预定目录的筛查结果，不是6份互相独立的发现。

- 亚洲主队，洲外对手减同分区对手：−14.6057个百分点，范围[−26.2155，−2.9958]。
- 欧洲主队，同方向对手关系差：+17.5044，范围[+7.3242，+27.6846]。
- 西非减其余撒哈拉以南：+9.5529，范围[+1.8925，+17.2133]。
- 北非减其余撒哈拉以南：+19.3111，范围[+8.4165，+30.2057]。
- 南美洲减加勒比地区：+14.1600，范围[+1.2440，+27.0760]。
- 中美洲减加勒比地区：+13.6006，范围[+0.0348，+27.1665]；下端非常接近零，应作为边界性结果谨慎讲述。

“其余撒哈拉以南”明确不含已经单列的西非。对手的“洲/分区”按项目研究分类解释，保留土耳其欧洲/南欧、伊朗西亚和澳大利亚亚洲/东南亚三项约定。

这6项在本次列出的可算描述对照中没有方向翻转，但**变体没有重新校准区间**，不能据此说它们在所有变体下仍“统计显著”。洲外与同分区对手的实力、赛程选择可能不同，不用旅行、文化或经济机制解释尚未验证的差异。

71个可算主客条件率均已生成范围，实际平均宽度约78.4048个百分点，仍很不精确。这个数取自当前实际应用，不混用模拟情景的平均宽度。它们只是局部不确定性展示，没有自动生成对0.5的主场优势检验，也没有把不同参考的地区排成世界实力榜。

补充的“北非减全部撒哈拉以南”为+16.0825个百分点，正参考贡献的比赛并集5,868场。它是新定义的描述目标，不属于原198个已校准目标，没有区间，也没有借“北非减西非”当基线。

**可用表述：** 地域差异有若干条件证据，但应结合对手构成、共同参考和样本支持解释；下一问再检验加入赛前实力后这些信号保留多少，不预设答案。

## 5. 本地重跑与A的复核方式

先按[本地环境指南](../../文档/02_环境配置/克隆仓库后的快速上手.md)使用仓库自己的解释器和依赖，工作目录为仓库根目录。实际本轮为Python3.14.8、NumPy2.5.4、SciPy1.18.1、Matplotlib3.11.2，中文图使用已登记字节指纹的Microsoft YaHei。

```powershell
python -m scripts.analyze_reliability --stage check
python -m scripts.analyze_reliability --stage all
```

第一条只检查，第二条做完整计算；结束会打印新运行的`run`路径。随后将它填入：

```powershell
python -m scripts.audit_reliability_analysis --run outputs/logs/reliability/这里填实际的新运行目录
```

最后一个路径是填写说明，不是可以原样复制的固定目录。Windows PowerShell中也可自动取得新run再核查：

```powershell
$applicationOutput = python -m scripts.analyze_reliability --stage all
if ($LASTEXITCODE -ne 0) { throw "主程序失败，请先查看报错" }
$applicationRun = ($applicationOutput | Select-Object -Last 1 | ConvertFrom-Json).run
python -m scripts.audit_reliability_analysis --run $applicationRun
```

已有独立审计文件会拒绝覆盖，这是历史保护。对已审计结果做一次自己的独立复现，应像上面一样创建新运行，再核验新run；不要先删除已有审计。相同环境、输入与代码下，核验时还可加`--compare outputs/logs/reliability/applied-20261028T085135016736Z-34239452`；不同绘图环境不要要求同一分析身份。此次已执行的完整参数和两次证据见第4节链接。

主程序支持`check/infer/sensitivity/report/all`。分段执行时必须用`--run`延续同一未完成运行，report要求infer和sensitivity都完成；源码、输入或身份变化会拒绝继续。默认all最便于本地使用。同内容身份已存在时比较重算字节，完全相同才复用；不会覆盖不同内容。临时计算目录在被忽略的`outputs/test_tmp/reliability/`，正式表图只保留一份内容身份目录。

不同机器的字体、绘图库或环境不同，分析身份可能不同。先比较数值表和数学定义，不要求跨不同环境的图文件字节完全一致。不能任意改原模型/缓存或数据后仍声称复现了本次结果；程序实现的是本次冻结协议，不是任意改参框架。

A还应检查：固定参考删无关年份是否记“不涉及”；主客双角色是否同时删队；恢复澳大利亚原标签后是否仍保留大洋洲整体合并；正参考缺层是否保留空值；变体是否没有冒用旧区间；区间跨零是否被误写成“没有作用”。未经A本人执行，不填写组员复核完成。
