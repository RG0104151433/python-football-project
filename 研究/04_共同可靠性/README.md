## 2. 为什么数学逻辑可以共用，但不是同一个检验机械套三次

三问都先求组内主胜比例，再按已规定参考加权或作差。第一问在年代内统一两类赛事比例；第二问在两类赛事间统一年代比例，滚动部分统一窗口内年份比例；第三问按各目标参考统一年代×赛事构成。主胜指标统一为Y_i=1（主胜），否则0，平局仍在分母。

固定赛程、分母和参考后，可将目标写成：

\[\widehat T_j=\sum_i a_{ji}Y_i.\]

于是两个目标一起变化的程度满足：

\[\operatorname{Cov}(\widehat T_j,\widehat T_k)=\sum_{i,\ell} a_{ji}a_{k\ell}\operatorname{Cov}(Y_i,Y_\ell).\]

这只是固定系数下的恒等式，不要求先假定每场独立；它说明可共用逐场目标、依赖结构和联合估计框架。它没有给出未知比赛关联怎样估计，也没有保证正态近似或95%区间成立。若将赛程/参考也视为随机，系数会变化，不能不加说明就照用这个条件公式；必须先决定推断对象。

共同接口还须显式保留单位和方向：第一、二问率差主要以百分点存储，第三问同时保存概率差和百分点；不得混用100倍换算。统一逻辑不要求各题分组、人群、参考、检验族完全相同，也不强制把全部目标并成一个p值。
