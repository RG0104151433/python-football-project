# 第四问：前三问的结论能支持到什么程度？

**中文** | [English](README.en.md)


本页为2026-11-12核对后的当前入口；采用样本和结论未变，推导及旧阶段记录见文末历史说明。

## 研究问题

怎样在比赛共享球队、年份和共同波动的条件下，判断前三问差异的不确定性与稳定性？

## 分析方法

固定目标和参考，比较并改进候选模型，通过已知答案的模拟检查，再对实际目标计算模型条件范围及规定的描述敏感性。

## 主要结论

198个目标获得模型条件范围，94项缺层留空；另有324场景、26,704行敏感性对照。年代与赛事的重点范围跨零，部分地域比较保留条件方向支持。

## 解释限制

范围依赖选定模型条件，不是现实分布的无条件覆盖保证；敏感性变体没有自动获得新校准区间，也没有在此控制赛前实力。
