# 第一问：主场表现是否随年代变化？

**中文** | [English](README.en.md)


本页为2026-11-12核对后的当前入口；采用样本和结论未变，推导及旧阶段记录见文末历史说明。

## 研究问题

1980—2024年，主队获胜比例怎样变化？统一友谊赛与其他赛事的比例后，观察到的差异是否改变？

## 分析方法

对同一24,917场按五个时期分组，先计算实际比例，再以同一赛事构成进行比较；可靠性与敏感性衔接第四问，实力因素衔接第五问。

## 主要结论

直接主胜率并非单调变化。统一赛事比例后，2010年代与2020—2024相对1980年代分别高0.5019和1.8100个百分点；第四问两项模型条件范围均跨零，不能确认年代改善方向。

## 解释限制

末组只有五年；这是比赛平均表现而非纯主场因果。历史描述与后续含实力分析分别保留，不能混用样本或结论。
