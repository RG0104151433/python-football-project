2. [赛事类型](02_赛事类型差异/README.md)：友谊赛与其他比赛比较，并统一年代构成。
3. [地域差异](03_地域差异/README.md)：主队分区与对手构成分别考察。
4. [共同可靠性](04_共同可靠性/README.md)：在明确模型条件下评价前三问的不确定性。
5. [赛前实力](05_赛前实力/README.md)：按时间先预测后更新，检验实力和背景的预测贡献。
6. [历史参考周期](06_历史参考周期/README.md)：比较记忆长度，未得到普遍最佳年数。
7. [地区有效性](07_地区有效性/README.md)：检查预测适用范围及地区差异。
