## 研究价值与后续主线：讨论提议，尚未采纳为新设计

R20261027-04。完成九问本身不保证重要发现。建议把主线从“列出各组胜率”推进为：**历史主场胜率差异有多少与已观察的赛程构成和赛前实力相关，剩余信息能否稳定改进未来比赛预测？** 这仍是待用户讨论的总题提议，不自动批准第五至第九问模型、特征或评价协议。

前三问保留独立的描述价值：检验粗平均是否遮蔽组成变化/分区差异，明确比较人群与数据支持。第四问检查能说多强；第五问是解释性转折，区分胜率高与控制赛前实力后的剩余主场信号，但仍非完整因果识别；第六问比较历史信息的有效期，第七问检查方法能否跨地区泛化；第八问赛前锁定未来概率预测作应用展示；第九问用严谨的基线/增量对照判断这些信息是否真正改善预测。第八问少数未来赛果不能独自证明方法优越。

至少考虑比较仅实力、实力加统一主场信息、再加入少量事先确定的赛事/地域/时间信息；具体模型和比较族之后讨论。按时间验证、训练期内选择历史窗口/参数、保留未用于选题调参的测试期；不能把目前观察到的差值直接塞进过去预测而泄漏未来，也不将Elo的预期积分当成主胜概率。用胜平负概率质量和校准评价，不能只数猜中几场。

可能得到三类有意义答案：差异控制实力后仍存在且能增进未来概率预测；有描述/解释差异但无足够样本外增量；原有差异主要随样本/构成变化而改变。只有设计、数据支持和精度足够才允许后一类负结果；区间宽或样本少只能称证据不足。若到第五问仍只能再列胜率、到第九问没有独立评价，应收缩和重构主线，而非用更多分类包装贡献。
