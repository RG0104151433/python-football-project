## 第一至第五问：从描述到含实力分析

1. [年代变化](01_年代变化/README.md)：统一赛事构成后仍有小幅年代差，但第四问重点范围跨零，不能确认改善。
2. [赛事类型](02_赛事类型差异/README.md)：友谊赛全期主胜率较低；年代构成调整会改变差距，近期变化不支持稳定反转。
3. [地域差异](03_地域差异/README.md)：覆盖大洲、分区与主客组合，缺层不补零；对阵构成和项目分类约定必须说明。
4. [共同可靠性](04_共同可靠性/README.md)：对前三问提供限定模型条件下的范围与敏感性，不能把同一批比赛当三次独立验证。
5. [赛前实力](05_赛前实力/README.md)：实力承载主要预测信息，背景有较小增量；30项条件参照和24项未准入明确区分。
