## 第一问：主场表现的年代变化

问不同年代的主队表现怎样变化，以及采用相同赛事构成后比较结果怎样改变。[阶段成果](01_年代变化/README.md)使用当前24,917场，分析eras-fifa-dddf11dd6dc0b7531b88。描述结果与交接材料完成；正式可靠性由第四问统一处理。

## 第二问：友谊赛与其他赛事的差异

问两类赛事的主胜率相差多少，以及采用相同年代构成后差距怎样变化。[阶段成果](02_赛事类型差异/README.md)使用同一24,917个比赛ID，分析tournaments-4893e38db46f83f6c219。独立描述阶段已结束；HTML、论文相关工作和组员独立核验按用户要求暂缓，未冒写为完成。

## 第三问：地域差异

问不同足球地区的主胜率相差多少，统一年代和赛事构成后差距怎样变化。原“地域扩展”现正式列为第三问。

当前是方案准备，尚未生成地区映射或分析结果。地区定义、比赛当时的归属来源、未知归属与分层覆盖等仍需明确，详见[已有地域准备](../文档/01_项目方案/前三项研究的数据标准与清洗脚本设计.md#141-地区不同主场表现是否也不同)。现有24,917场是母样本；若地区映射只能覆盖子集，应登记差异，不悄悄改前两问结果。

## 第四问：前三问统一分析

对年代、赛事类型、地域三问统一开展可靠性与敏感性分析，分别判断各项结论能支持到什么程度。原“两问共同可靠性”现在扩展为第四问；[具体任务](../文档/05_团队协作/分工与交付/04_两题共同可靠性与敏感性.md)文件名沿用旧名。

第四问包括相关结构与方法适配、模拟验收、正式不确定性、参考及样本敏感性、多个比较与滚动曲线的处理。它不是把三问合成一个p值，也不是把同一比赛的三个视角当作独立验证。目前前两问输入已齐，第三问输入未齐；正式共同分析尚未实现或运行。可先讨论方法与验收原则，实际联合运行须绑定前三问的真实结果与目标定义。

## 第五问：赛前实力评价与调整

原第三问改为第五问：先用比赛之前的信息评价双方实力，再研究考虑实力差异后主场信号怎样变化。现有[数据与评级接口设计](../文档/01_项目方案/前三项研究的数据标准与清洗脚本设计.md)保留，Elo及实力分析尚未实现。不能把本场或未来结果用于本场赛前实力；调整实力也不自动获得因果解释。

## 后续问题暂不编号

以下均为已讨论过的备选，不因列出就成为必交或已开工任务；先确定具体研究对象和工作量，再分配序号。

- **最合理的历史参考周期。** 比较全历史、固定回看窗口或旧比赛逐渐降权，研究哪种方式适合评价当前实力或预测；需要时间验证，与第二问用于展示的十年滚动窗口不同。
- **不同地区的方法适用性。** 考察同一历史参考规则或实力评价方法在不同地区是否同样有效；属于规则有效性或预测评价，区别于第三问描述地区主胜率。
- **将方法迁移到俱乐部比赛。** 另选联赛或赛事，评估清洗、评级和分析方法能否迁移；俱乐部与国家队数据及评级分别管理。
- **用俱乐部和球员信息帮助国家队研究。** 获取比赛时点的球员所属俱乐部、出场或近期状态，研究能否补充国家队实力信息；区别于直接分析俱乐部比赛。
- **预测未来国际比赛日。** 在明确时间边界和历史回测协议后给出胜平负概率，再对真实赛果评价；尚未实现，不用描述差异冒充预测模型。
- **评级修正能否改善预测。** 研究主场、赛事或净胜球等评级修正是否提升预测表现；这是早期暂缓的预测研究，不是现在第四问的统一可靠性分析，需要独立的回测及参数选择协议。

外部FIFA排名等仍可作为核对或模型参照来源，不单独分配研究问题编号。
