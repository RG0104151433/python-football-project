## 1. 使用什么依据

已保存[FIFA官方报告原文](../../参考资料/数据来源/FIFA/FIFA_Financial_Report_2018.pdf)，下载自[FIFA原文地址](https://digitalhub.fifa.com/m/337fab75839abc76/original/xzshsoe2ayttyquuxhq0-pdf.pdf)。PDF第149—150页列211条会员及加入年份；抽取后检查序号1—211完整、代码不重复，保留原文页码和带斜线的年份。编辑截止日为2018-12-31，不把它称为1980—2024逐年的完整名单。

[2016年FIFA大会记录](https://inside.fifa.com/organisation/congress/news/66th-fifa-congress-zurich-2016-2878197)提供科索沃、直布罗陀的加入日；FIFA关于南苏丹的回顾提供2012-05-25。其余只有年份的加入年全部待核，绝不编成1月1日。[2024年官方治理报告](https://inside.fifa.com/official-documents/annual-report/2024/governance/fifa-council)提及211会员，但数量相同不能证明所有年份的组成和连续状态都已核验。

当前临时规则：双方均有官方加入依据，过了已记录加入年份或确切加入日，且未落入明确的历史关系待核区间，才能在**连续性假设**下暂纳入。重新加入前的旧时期、已消失足协和未映射标签不据现名单自动判非会员。暂停比赛资格也不自动等于失去会员身份；本轮未审完全部制裁史。2019—2024及其他连续时期的处理是明示工作假设，不是已核实逐日记录。

FIFA报告中的211个标签已与来源比赛标签逐项建立明确对应，其中不同拼写由AI人工列明，没有模糊匹配；尚无队友独立核对。历史名称和继承仍单独待审，不把苏联、南斯拉夫等简单并入现代国家。旧的Silesia单例提案不再作为唯一筛选规则，本版统一按会员证据和未决处理。

## 2. 逐步检查六步是否完整、合理

1. **保留基线：完成。** 旧快照、清洗、第一题和实际源码已保存；旧输入/表图能够继续校验。它是探索性对照，未被改称最终冻结。
2. **盘点与排序：完成。** 337个来源标签、335个清洗标签、308个旧研究标签已对账；13个程序线索只决定先查谁，未被当成全部疑点或错误名单。
3. **查证和决定：部分完成。** 已有官方PDF211条加入记录、明确名称对应和少数确切加入日；但原会员/继承、缺失日期、完整退出/恢复记录仍不足。新FIFA准则解决了“按照什么选”的问题，没有自动解决“证据是否齐”的问题。上游旧称区间继续只是线索。
4. **决定校验与预演：首版完成，完整历史规则验收未完成。** 旧37提案和新会员规则均有范围检查；本轮新增年度/确日边界、完整匹配、来源哈希和逐场去向检查。非会员依据与待核分开，未决不会误写成false身份。复杂继承、撤销重放和制裁全史没有实现/验收。
5. **发布：临时包完成，最终包未完成。** 覆盖全部48,102场清洗比赛，每场一行；保留双方原标签/编号、会员证据/状态、资格与原因、旧样本去向及版本。状态published_provisional、full_history_verified=false、人工复核待完成。它是会员筛选覆盖表，不是已完成全部历史实体拆分的名录；不能用于Elo继承或最终人口覆盖声明。
6. **接入：第一题有条件重算完成，第二题输入约定完成、计算未开始。** 新入口先校验身份包和原清洗，再用原统计方法重算；没有重写旧结果。第二题尚无实现，不能声称已有第二题实验。本阶段为其固定共同过滤接口；完整会员证据补齐后，两题再统一重跑。正式可靠性仍按原决定后置。

这六步的顺序合理，但不是“前一步做过一次就无条件放行”。实际进入第五步后发现证据仍不足，发布只能限定用途；第六步重算也不能反过来证明人群已经正确。

## 3. 真实结果及对原有工作的影响

基础清洗仍是49,945条原始→48,102条纳入，另1,803条截止日后、40条候选隔离。没有改任何原始比分、日期、主客排列或中立标记；原清洗版本无需因本次会员筛选重新编号。

旧第一题26,055场中：24,279场在当前假设下保留；246场有早于已记录加入时间的依据；1,530场暂存待核，不能称为错误或全部非会员。这三项合计26,055。全清洗表的其他中立场、早期比赛等亦有逐场去向，但本阶段不批准1980年前数据供Elo使用。

1,530场待核包含目前未匹配到2018名册的历史/地域标签、加入年日期边界及历史继承区间。多项原因可落同一场，按双方状态统计时不能把各原因数量直接相加。比如捷克斯洛伐克、东德、南斯拉夫是需要补官方历史证据的旧足协，不能因不在现名册就判它们从未加入。来源不完整会更影响早期年代，临时样本可能引入年代选择偏差。

第一题五年代的原始主胜率，旧版→临时版为：1980年代49.0511%→49.4647%；1990年代50.5724%→50.4781%；2000年代50.9415%→50.9370%；2010年代50.5322%→50.4450%；2020—2024为50.8805%→50.8562%。对应场数由3,741/5,066/7,116/6,952/3,180变为3,176/4,602/6,777/6,629/3,095。

友谊赛共同占比由38.5339%变为38.2223%，因此不能只删几场却沿用旧权重。统一赛事构成后的“2010年代减1980年代”由+0.8122变为+0.3083个百分点，“2020—2024减1980年代”由+2.1046变为+1.6026个百分点。方向在这个临时处理下相同，幅度发生变化；不能据此宣称最终结论稳健或显著。这里同时变化了样本和共同参考，差值不是纯粹的会员资格因果效应。

原方法公式可以继续使用；原26,055场结果保留为核验前基线，不能与新表图混用。旧118项收尾核验只覆盖旧版，不替新版本背书；新版本有新的字段、对账、直接计数和运行校验。正式区间、共同可靠性和A/B实际复核仍未完成。所有图表/展示素材必须标明临时版及其假设。

## 7. 具体还缺什么证据，怎样查

目前1,530场研究内待核按“历史关系→未映射→加入年”的优先顺序分成三个互斥主因：286场历史关系，1,121场没有匹配到2018名册，123场加入年内缺确日。这个拆分避免同一比赛重复计入，某队的补证场数彼此仍可能重叠。另有24,279场暂纳入所依赖的连续性假设，需要持续检查；246场加入前分类也可因发现前身/临时会员证据而重新裁定。

**第一类：旧足协和没有当前对应的标签。** 要证明的是它在目标比赛日期是否为FIFA会员，而不是现在是否存在。优先例子：捷克斯洛伐克120场、东德102场、南斯拉夫86场；这些只是该队在待核研究比赛的参与次数，不能加起来当总待核数。马提尼克131场、瓜德罗普96场、法属圭亚那94场等同样在队列中，但不能把它们与已消失足协混为同一事实结论。须分别取得当年FIFA名册、会员变动决定或足够清楚的官方非会员说明；洲足联会员资格不能替代FIFA会员资格。

**第二类：来源现代标签背后的历史对象。** 俄罗斯来源标签对应待核101场、塞尔维亚108场、库拉索68场，另有也门等。要查苏联/CIS/俄罗斯、南斯拉夫/塞黑/塞尔维亚、荷属安的列斯/库拉索和南北也门之间的会员代表关系与生效边界。仍保留原标签，不因结果继承就把球队历史强弱或人口范围认作相同。当前历史例外表用整年边界保守暂缓，不能把这些1月1日/12月31日误当已核实的官方生效日。

**第三类：加入年份里具体哪一天。** 2018官方表常只到年份，加入当年的比赛不一定都在加入之后。优先例子：拉脱维亚1992年12场、立陶宛1992年10场、捷克/北马其顿/斯洛伐克相应加入年各8场、南非1992年7场。按受影响比赛日期找FIFA大会记录、通告或明确日期的官方历史回顾，不借用建国日、足协成立日或加入UEFA的日期。只需要查到足以区分目标比赛的日期范围，不必机械要求每个国家都精确到日：若官方记录已证明该队在最早待核比赛前加入，可解决这批比赛。

**第四类：会员连续状态。** 当前按加入记录向后延续，尤其2018名单不能直接证明2019—2024全部状态；也须处理重新加入、退出、除名与临时停权的区别。需要相关时期官方名册加变动决定，而不是只有会员总数。并非所有更名都必须重新申请：能证明身份和会员连续的普通更名，只补说明，不为其捏造新加入事件。

不必逐场搜索26,055场，也不必机械下载45份年度名单。更省力且可审计的方式是：取得分析起点附近的会员基准名册，再补1980—2024间加入、退出、重新加入和继承的变动记录；按有效区间覆盖相关比赛。基准和变动链存在缺口的时期仍待核，不能只凭总会员数补齐。

查证入口和实际操作：

## 9. 早期年代受影响是什么意思

从同一批26,055旧研究比赛重新对账：1980年代待核441/3,741（11.79%），1990年代375/5,066（7.40%），2000年代324/7,116（4.55%），2010年代305/6,952（4.39%），2020—2024为85/3,180（2.67%）。加入前与待核合计暂未纳入的比例分别为15.10%、9.16%、4.76%、4.65%、2.67%。证据见[分年代对账](../../outputs/logs/team_identity/evidence-and-reference-audit-20261024/pending_by_era.csv)。

这句话指比例不均，不是说全部待核都在早期。缺失历史档案会让1980年代少一些真实会员队的比赛，而近期更容易与当前名单匹配。若这些被暂缓球队的胜负或赛事构成与保留球队不同，比较结果会同时受到“真实年代差异”和“资料是否查全”的影响。不能断言偏差一定向上或向下，也不能以方向未变宣布问题已解决。

解决顺序应当是：先补会影响现样本的官方资格证据→按统一规则恢复/排除且保留去向→发布新会员版本→统一重算第一题和将来的第二题。之后再在两题共同可靠性任务中考察确认样本与有根据替代口径的差异。不能现在给未查明球队猜资格或人为加权，也不能靠加宽置信区间解决系统性样本错选。若最终无法补齐，应缩小结论对象或单列证据覆盖不足时期，并如实说明；不按胜率临时挑时期。
