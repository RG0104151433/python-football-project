## 研究问题

## 分析方法

在基础清洗之后按球队身份、时间规则和逐场决定确认去向；每条决定保留比赛ID及来源。

## 主要结论

26,055场候选中纳入24,917场、排除1,138场，当前范围待定0场；组长明确采纳的117场已进入样本。

## 解释限制

采纳只针对本研究范围，不等于全球全部历史身份、场地和比赛事实都已独立核验，也不自动批准评级实体合并。
