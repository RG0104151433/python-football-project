# 第六问准备：参考多久的历史更合适

本页是第五问的交接准备，不是已运行的第六问结果。候选周期、评价起点及具体实验顺序仍需在开始研究时确认；本轮没有选择“最佳年限”。第五问的当前材料入口见[收尾与下一问交接](../05_赛前实力/第五问_收尾与下一问交接.md)。

## 先确定究竟要改变哪一种历史长度

“参考过去几年”有两种不同含义，不能一次同时修改后再解释原因。

1. **球队评分记忆。** 过去的比赛怎样影响今天的实力。现有评分有扩散和跳变，虽然从1950开始学习，并不意味着1950年的比赛与最近比赛权重相同。
2. **共同模型训练窗口。** 已有逐场赛前实力保持不变，只改变估计“实力、年代、赛事、地域与主胜联系”时使用多少年的研究比赛。

建议先做第二种，能够直接复用第五问赛前评分和按年向前的评价接口。评分记忆另设一组实验，避免把评分改变和共同模型训练改变混成一种效果。

## 有限候选与公平比较

可讨论2、4、8、12、20年和累计历史。它们是拟议候选，不是已优化的参数。窗口按日历年定义，起止日写清楚；同一年内全部方案预测同一批比赛，不能删掉冷启动或预测不好的比赛来提高成绩。

第五问共同分析从1980开始。若希望公平比较最长20年训练窗口，建议统一外层评价2000—2024：2000年之前已经有1980—1999的20年研究资料。1990年只有10年共同研究资料，不能把它写成真正使用20年训练。1990—1999可另外用于较短窗口的探索，不能混入全部候选的公平比较。

第五问按年预测结果中，2000—2024共16,599场，应该先在这个相同子样本重算累计历史基准，不能把第六问的成绩直接与第五问1990—2024共21,413场的总成绩相减。

## 时间顺序怎样保持正确

- 对每个外层预测年，只用此前资料选择周期和拟合。可以在更早年份的内层滚动比较中选周期，然后评价下一年。
- 不能看完2000—2024全部结果，挑最优周期，再把同一时期称作独立验证。历史已用于研究选择的事实仍保留；新增真实盲测留给后续问题。
- 当年各场实力仍只使用该日期以前的赛果，同日比赛先全部预测再学习；年度模型不能用当年结果拟合后回填预测。
- 训练窗口短时，某些地区或年代没有训练记录，继续使用明确的先验/正则化并登记，而不是冒充参数已被充分估计。

## 如果改变评分记忆，必须另外解决什么

真正的有限评分窗口不能在左端加载一个包含更早历史的完整检查点，否则仍偷偷保留窗口外的信息。若在左端重置，就固定一致的初值、先验方差、热身和身份处理规则，记录由此增加的冷启动，并在共同测试样本上评价。

改变共同模型训练窗口时则相反：可以沿用完整评分轨迹，明确它研究的是模型估计窗口，不撤销旧比赛已经提供的实力学习信息。两类实验分别命名。

扩散q、跳变率、友谊赛学习权重0.65及概率校正先固定。若同时调这些参数，必须另定义选择层；不能将多参数优化的提升全部归给历史周期。

这里的0.65是现有评分器削弱友谊赛实力信号的参数：代码以κ=(1−ε)α混合实力赛果概率与均匀背景，不是把友谊赛场数或每次更新机械乘0.65。第六问应保持这条已采用规则，不能在改窗口时顺便更换它的含义。

缩短训练窗口也会减少样本、改变所覆盖年代和地区，不只是让模型“更重视新人”。本问首先评价哪套具体训练规则更好预测，不能把差异直接解释为国家队换代速度的因果效果。先保持评分、模型家族和先验规则相同，再逐一改窗口；每年保存实际训练场数、未出现类别和拟合失败，不能只保存最佳总成绩。

年度模型的编码锚点和权重须继续从当年的训练行重建；第五问已经更正了沿用全期编码的首版，不能在第六问又引入这个问题。若使用固定精度的正则先验，应说明它怎样随可用样本影响估计，不能一边改变窗口一边暗中换先验。训练窗口比较的预测误差与参数/效应的不确定性是两件事，旧第五问的30对象范围不会自动覆盖新问题。

## 下一次讨论需要关闭的决定

先确定从“共同模型训练窗口”还是“评分记忆”开始；再确定最长候选和共同评价起点、内层选择年份、主指标与分组验收。主指标建议对数损失，Brier、校准和二元准确率并列说明；不以单一准确率或训练损失挑年限。

原始数据和旧结果不覆盖。每个窗口生成独立版本、逐场预测和训练边界，并保留失败。完成问题时继续同步研究日志、阶段README、论文与汇报索引及展示材料。
