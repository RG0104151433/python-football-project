# 第六问规划：历史参考周期、实力评价与预测成本

**当前版本R20261031-07：** 已整理研究目标、已有资源和推进顺序。本页是供讨论的规划，尚未完成数学方案审定或冻结实验协议；没有第六问专用代码、窗口比较结果或最优年限。第五问结果与封存不改写，当前入口见[第五问收尾](../05_赛前实力/第五问_收尾与下一问交接.md)。

## 1. 这一问究竟研究什么

主线是：**国家队预测应该保留多久的历史，才能兼顾对当前实力的判断、赛果预测表现和计算成本？**

用户提出三个相连但不同的目标：

1. 评价当前相对实力时，使用多久的历史更合适？
2. 预测下一场赛果时，整套方法怎样使用历史更合适？
3. 在预测表现接近时，怎样减少模型训练和更新的运算负荷？

这里把“训练负荷”理解为模型的运算时间、计算量、内存与重训频率；球队的体能或日常训练负荷不在现有数据中。

“过短可能信息少，过长可能信息过时”是待检验的取舍，不能先认定两端一定更差。累计历史方案已经允许实力变化，可能胜出；也可能多个周期表现接近。结论只针对指定模型、候选、任务和资料范围，不承诺找到普适、唯一的最佳年限。

## 2. 与上一轮建议的区别

上一轮建议先固定第五问评分，只改变共同预测模型使用多少年资料训练。这是第二个目标的一部分，是较容易实施的切入口，没有完整覆盖评分记忆和计算负荷。

本版把三个目标都纳入研究，但分开改变因素：

- **评分记忆周期：** 改变哪些旧赛果参与生成今天的赛前实力，后续赛果转换的模型结构和训练协议先保持一致。
- **赛果模型训练周期：** 赛前评分轨迹保持不变，只改变估计“实力、年代、赛事和地域与主胜之间的联系”时使用的训练年限。
- **整套方法的取舍：** 两部分分别比较后，再对少量有依据的组合比较预测表现和实际成本。

如果两项目标都同时调整整套方法、最后只看同一个预测成绩，就会变成重复研究。两个最合适的周期可以不同，也可能相同，需要实验回答。

## 3. 实力评价和赛果预测，分别怎样判好坏

### 3.1 真实资料没有“真实实力”标签

我们能观察赛果，不能直接观察每队真实实力。因此，不能凭评分平滑、排名符合印象、接近FIFA排名，就认定某个周期最准确；外部排名至多是旁证。

在真实比赛上，可以先检验：某种历史政策生成的赛前评分，能否更好地预测后续表现。需固定下游模型的结构、训练时期、先验和选择规则；各评分方案的转换系数可仅由同样的过去资料估计，不把在一个评分分布上拟合的系数未经检查强套到另一个分布，也不拿测试期重调尺度。

这样得到的是“评分对后续预测更有用”的证据，不是直接测到了真实实力误差。

### 3.2 若要评价实力追踪本身，须补已知实力的模拟

拟设计固定、渐变、突然变化等不同潜在实力路径，先明确真实相对实力，再独立生成赛果，让各周期去追踪。比较相对差距误差、稳定阶段波动、变化后的跟进与不确定性；不因球队分数有任意共同平移，就用未经处理的绝对分数误差排名。

真实路径和赛果生成规则不能由被比较评分器自己的输出定义；也不能只模拟一种完全偏爱当前算法的机制。

**第五问的360个世界不能直接当成本问的真实实力答案。** 现有`src/strength_inference/worlds.py`根据过滤器历史状态生成已知赛果概率，主要用于检验效应估计与反馈；没有一条与估计器独立、可直接用于本任务的潜在实力真值轨迹。赛程与计算接口可借用，验证对象需要另设计。

以上模拟尚未实现；它提供模型内追踪证据，不证明现实国家队恰好按该规律变化。

### 3.3 赛果预测先保持现有二元任务

主任务继续是“主队赢球 / 主队不赢球”，平局与客胜均属于非主胜。初期不同时扩展完整胜平负、净胜球、球员或经济数据。

主指标建议对数损失，Brier分数、平均概率偏差和二元准确率作补充。另保留年度、友谊赛和其他赛事的结果，防止总体小幅提升掩盖局部明显退步。地区只先做必要诊断，不提前承担第七问的系统地区有效性研究。

这些指标的排序和是否设置分组门槛，须在正式对比前审定。不能用训练集拟合成绩选择周期。

## 4. 窗口必须怎样定义

### 4.1 有限候选与两种累计历史

建议从2、4、8、12、20年和累计历史开始，均为待审定候选。

- 评分累计历史基准沿用1950起的合资格学习资料，并按比赛日期更新。
- 共同模型累计训练基准沿用1980起的研究资料，每年只用此前比赛拟合。

两者的“全历史”不是相同起点，也不意味着每场旧赛果对当前判断的影响相同。现有扩散和跳变规则已产生动态记忆；不能把窗口长短直接等同于国家队换代速度。

### 4.2 共同模型窗口可以按完整日历年定义

例如预测2020年时，5年训练窗口为2015-01-01至2019-12-31。年度系数与编码只从这些训练行生成；球队评分仍只用每场之前的信息，同日先预测后学习。

少数据、缺类别或历史不足必须显式记录，使用已约定的先验规则，不删除预测不好的比赛。固定先验在小样本下作用更大，应说明这一取舍，不能暗中修改先验来追求最好结果。

### 4.3 严格评分窗口不是简单截掉输出表

如果要求某场只参考过去W年，必须确认评分及其全部状态没有夹带窗口外赛果。旧的累计检查点包含更早信息，不能直接加载后冒称纯W年历史。评分均值、协方差、主场项、历史计数和其他状态都属于检查范围。

此外，两种操作不同：

- 每场日期都严格使用此前W年，窗口左边界持续移动。
- 每年年初重置，学习此前W个完整年份，再顺序吸收当年赛果；年末实际可能使用约W+1年。

后一种若采用，应称年度截断方案，不能标成逐场严格W年。建议先对严格定义进行小样本成本试算，再审定正式实现；近似方案须单列，并与严格结果核对，不能悄悄替代。

每种评分方案用于训练下游模型的历史特征，也必须是当场之前按该政策形成的评分，不能用今天重算的最终分数回填过去。

初值、热身和身份处理要一致并记录。额外热身若使用窗口外赛果，就改变了问题，不能藏在初始化里。扩散、跳变、友谊赛参数0.65、主场与既有校正规则先固定；如果后来改变校正训练年限，也要另登记，不能藏成第三个可变历史窗口。

## 5. 时间安排与公平比较

现有预测表的只读核对显示，三个方案都有相同样本：2000—2024共16599场，2010—2024共9727场。这是已有资料计数，不是第六问运行结果。

### 5.1 固定候选比较：建议2000—2024

1980开始的共同研究资料，到2000年才有20个完整训练年份。因此，六个固定候选可在2000—2024的同一16599场上回顾性比较。先在这批比赛上取出第五问累计基准，不能与1990—2024共21413场的总成绩直接相减。

完整比较能描述哪个固定候选在这批历史中最好；看完以后选出的第一名，不能把同批成绩当成独立确认。

### 5.2 自动选窗规则：建议另设时间顺序

“2000有20年训练资料”不等于“2000之前已有足够的20年窗口预测成绩供内层挑选”。1980前资料不能未经新设计就纳入共同模型训练来补这个缺口。

拟议安排：

- 2000—2009作为候选与规则的开发、内部评价资料，共6872场。
- 2010—2024的同一9727场评价只用过去成绩选周期的规则。
- 预测2010时仅用2010前的候选表现；预测2011时可加入已发生的2010年结果，再选择下一年，始终不看当年未来赛果。

评分记忆候选与少量联合组合也只能用开发资料筛选，不能先看完2000—2024再选择组合，把后段重新称作未见测试。选择规则、可接受差距和查看安排应在读取候选特有的后段成绩前固定。

这些时期是本版建议，不是已冻结协议。全部历史已被项目研究复用，即使严格保持时间顺序，也不称新增真实盲测；后续前瞻验证属于第八、九问。

## 6. 如何研究负荷与预测表现的平衡

先分别报告：首次建立评分/模型的总成本、历史回测成本、日常更新/重训成本、预测开销和峰值内存。记录硬件、软件、线程、缓存是否命中、训练行数及失败；不同机器或不同并行程度的秒数不能直接排优劣。

**短历史不必然更便宜。** 累计评分可以只更新新赛果，严格滑动窗口却可能需要重新消除旧赛果的影响。现有评分器提供按日更新和状态恢复，没有直接验证过删除旧赛果影响的接口。成本必须实际量测，不能按年限想当然估计。

推荐先排除同时“更慢且预测更差”的方案，剩下的构成成本—表现取舍集合。这里的Pareto含义很简单：没有另一个方案既不更差、也不更贵，并且至少一方面更好。

若没有资源预算或愿意牺牲多少表现的标准，就不能宣称存在唯一的最佳平衡。可选两种决策方式，待讨论：

1. 给定时间/内存预算，在满足预算的方案中选预测较好的。
2. 事前约定可接受的预测损失差距，在足够接近且证据支持的方案中优先选便宜的。

不能把“没有检出显著差异”直接当成两方案等效，也不先随意给时间与准确率相加设置权重。预算、差距容忍度和等效判据目前均未确定。

## 7. 数学基础已有多少、还要补什么

已有可复用基础：第五问的评分更新、评分不确定性进入主胜概率的推导，以及概率预测评价。它们支持现有计算框架，不直接证明某个历史周期最佳。

在给定真实相对实力d的时点，均方误差可分成估计偏差平方与方差。这说明需要一起看跟进速度和波动，但只是组织分析的恒等式，不能据此推出最佳W，也不能预设长窗口偏差一定更大。

按时间向前评价的原则参考[Hyndman与Athanasopoulos第5.10节](https://otexts.com/fpp3/toolbox.html#time-series-cross-validation)。选参数与评成绩分开的必要性参考[Varma与Simon2006](https://doi.org/10.1186/1471-2105-7-91)：本轮只阅读原始摘要与结论摘录，虽已保存作者机构PDF，不声称全文定理已审核。该文分类器交叉验证研究不证明我们的国家队时间序列方案已有效。

写正式脚本前仍须完成：

- 真实资料上的评分用途指标，与已知实力模拟的追踪指标如何衔接。
- 严格逐场窗口、年度截断与缓存重用的正确性条件。
- 窗口选择与后续年度评价的完整时间边界，过去编码及训练规则。
- 同一比赛的预测损失配对、跨年/共享球队依赖与多候选选择带来的不确定性处理。
- 已知实力生成器如何避免只偏向当前评分规则。
- 负荷量测、实际差距容忍度与资源预算。

第五问原30对象范围和360世界验收不直接迁移到这些新目标。完整流程模拟与保留依赖的配对比较可作为后续验证候选，但适配、误差与预算尚待数学审定，不提前宣布新范围或检验通过。

## 8. 建议推进顺序与各步产物

1. **关闭研究口径。** 明确三个目标、两个历史层次、窗口定义、二元预测任务、主指标与时间划分。产物是可审读协议；目前仍待确认。
2. **审定数学与评价方案。** 解决第7节清单，给出已知实力模拟、时间选择与不确定性方法的适配和限制。完成后才定正式脚本结构。
3. **做小规模可行性试算。** 仅用开发资料和少量候选核对时间、状态、冷启动、数值与成本；据此冻结候选、资源上限和失败处理。没有通过这步不启动大规模评分重算。
4. **先比较赛果模型训练年限。** 固定第五问评分，逐年训练各候选；保存同场预测、过去编码、年份与全期指标。当前年度预测代码可作基础，不是现成窗口程序。
5. **再比较评分记忆。** 对窗口内合资格学习比赛重建各自赛前状态；按相同下游训练协议和已知实力模拟分别评价。保持同一真实预测样本，不删冷启动或差例。
6. **做有限联合与成本比较。** 用开发期选出的少量候选组合比较两层周期，记录三类成本和内存，形成取舍集合；不直接穷举全部组合后用同一测试集选赢家。
7. **完成可靠性与敏感性检查。** 核对逐场配对、年度稳定性、来源/初始化/窗口边界、选择过程和失败。结论可以是多个近似可用方案或没有可靠改进，不能强迫一个周期胜出。
8. **解释、归档和交接。** 分别回答评分记忆、赛果训练年限、成本取舍；区分历史第一名与按过去规则选出的表现。同步论文/汇报索引、HTML素材、版本登记和日志，再衔接第七问。

当前下一步是第1—2步的讨论与审定，不是立即编写或运行第六问模型代码。

## 10. 预计成果与结论边界

预计将产生窗口规则及边界台账、逐场评分/预测、年度与配对指标、开发期选窗记录、已知实力模拟的追踪诊断、成本/内存记录和最终采用理由。这些都是未来产物，当前不存在。

展示可围绕“保留多少历史才有用”“评分记忆与预测训练是否应相同”“多花计算是否值得”展开。可能出现唯一较好周期、多个表现平台、累计方案胜出或改进不足，不预填结论。

不把最优周期称为国家队换代的因果周期，不把各地区最优规则提前全部放进本问，不复用第五问旧统计区间，不把历史复用称为新增盲测。原始数据与第五问封存结果保留，记录每次真实操作和失败。
