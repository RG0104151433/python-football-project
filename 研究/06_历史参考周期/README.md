# 第六问：预测下一场比赛，过去应该记住多久？

**中文** | [English](README.en.md)


本页为2026-11-12核对后的当前入口；采用样本和结论未变，推导及旧阶段记录见文末历史说明。

## 研究问题

判断球队实力与总结预测规律，各自参考多少历史更合适？预测表现与计算成本如何取舍？

## 分析方法

分别改变两种历史用途，比较2、4、8、12、20年与累计历史，再比较少量组合及只看过去成绩的选窗；补充模拟与有限稳定性检查。

## 主要结论

当前方法与样本下，固定短窗和自动选窗未超过累计默认。将总结规律的资料缩为12年，这部分用时约省66%，主要后段平均损失相对增加约0.36%，因此未替换默认。

## 解释限制

没有找到通用最佳年数；省时只对应相关计算部分，损失变化不是准确率变化。2010—2024主要比较为9,727场，不能拿前三问分母代替。
