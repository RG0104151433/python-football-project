# 第二问：友谊赛和其他赛事的主胜率有何不同？

**中文** | [English](README.en.md)


本页为2026-11-12核对后的当前入口；采用样本和结论未变，推导及旧阶段记录见文末历史说明。

## 研究问题

两类赛事的主胜率相差多少？将年代构成统一后，差距怎样变化，随时间是否一致？

## 分析方法

使用与第一问相同的24,917场，计算整体与分年代比例、共同年代构成后的差异，以及36个十年滚动窗口。

## 主要结论

友谊赛主胜率48.3955%，其他赛事51.6418%；直接差为−3.2463个百分点，统一年代构成后为−2.8831个百分点。近期方向不同，但第四问不支持稳定反转的结论。

## 解释限制

滚动窗口共享大量比赛，不能当独立重复证据；第四问全期、近期和36窗的模型条件范围均跨零。赛事分类差异不等于比赛性质的因果作用。
