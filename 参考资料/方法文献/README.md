## 标准化与时间评价

Klein–Schoenborn的CDC技术说明支持共同参考构成，和方差估计分开。CDC/NIST网页是背景，不替代相关性处理；NIST本地页介绍Wilson。预测教材用于区分时间验证与回顾性标准化，受阻网页不冒充教材正文。

## 地理研究

M49提供统计标签，不证明会籍、历史继承或区内足球/气候相同。正值性文献解释缺层不能补造概率、限制样本会改变目标。McSharry与Liu提供国家队环境/分区先例，不直接移用指标或系数；登记中前者PDF下载失败，后者只读公开摘要/元数据。

当前采用地理主线；土耳其/欧洲、伊朗/西亚、澳大利亚/东南亚是项目约定，见[第三问](../../研究/03_地域差异/README.md)，M49原件见[共享目录](../../data/external/geography_sources/m49-20261026/README.md)。
