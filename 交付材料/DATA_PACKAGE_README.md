# Experimental data and archived evidence

Extract this archive into the same parent directory as Code.zip so that both merge into FootballProject/.

Included: registered original match files and external rules/records, selected cleaned and identity-reviewed inputs, adopted rating inputs, reported tables/predictions, and the archived local dependencies reached from the paper supporting guide and evidence registers. Original repository paths are retained. The separately supplied data_selection_plan.json and PACKAGE_MANIFEST.json list exact members and hashes.

Excluded: the virtual environment, Python caches, per-job/resume caches, unrelated historical experiment copies, thesis editing/build caches, and downloaded methods-paper PDFs. Original source files in the working repository were not deleted or moved. Selection is an evidence/dependency package, not a claim that every historical development run can resume from an omitted cache.

The original results data retain their CC0 attribution/license files. Supplementary source records keep their own provenance; no blanket license is asserted over third-party material. Cited papers are identified by the report bibliography; redistribution of all downloaded publications is not necessary for running the submitted code.

Forecasts remain the sealed pre-match release; actual future outcomes are not inserted. Main outputs distinguish 49 binary predictions, three withheld cases, and 52 auxiliary three-class forecasts.
