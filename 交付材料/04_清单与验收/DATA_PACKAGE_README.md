# Compact experimental-data attachment

Extract Data.zip and Code.zip into the same parent folder so that their FootballProject directories merge.

This attachment contains the registered raw match files and licenses, supplementary rule and source records, the adopted cleaned and identity-reviewed tables, the joint-analysis input, paper-bound evidence, selected real-match predictions and final summary/comparison tables. Original relative paths and file bytes are preserved.

It deliberately excludes most simulated histories, per-world fitted outputs, resume caches, repeated intermediate rating datasets and bulky row-level diagnostic ledgers. These are retained in the full research repository; they were removed from the email attachment, not erased or relabelled as failed tests. The selection is listed in 交付材料/04_清单与验收/data_selection_plan.json. A manifest may mention historical files outside this compact attachment.

The combined package supports quick_check.py, raw-data auditing, the supplied targeted tests and inspection of the paper's registered evidence. It is not a complete checkpoint archive for every historical experiment. Strict archival replay of identity verification may also require predecessor outputs, original source PDFs or baseline archives from the full repository. Use the full repository or regenerate the omitted inputs before those commands; do not weaken archived hash checks.

The 52 forecasts remain sealed pre-match predictions: 49 main binary forecasts, three withheld cases and 52 auxiliary three-class forecasts. No actual outcomes or synthetic test scores were inserted.

Raw match data retain their CC0 attribution. Supplementary sources retain their own provenance and rights; no blanket license is asserted.
