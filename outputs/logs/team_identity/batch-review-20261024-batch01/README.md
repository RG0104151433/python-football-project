## 需要补正的部分

1. **没有新增可用于裁定的FIFA原始依据。** 11条证据中10条标记为线索，唯一FIFA主证据是已有的2018年报告。本批找到的足协、UEFA、新闻和历史文章有定位价值，但按已确认口径，还须取得支持相应比赛日期的FIFA记录。无需逐项追求精确到日：能够确定资格覆盖目标比赛的有据区间即可。
2. **年份和政治事件不能代替会籍边界。** A009/A011不能只凭报告中1923/1992的重新加入年份，就认定1991年的拉脱维亚/爱沙尼亚必非会员；应保留待核并查恢复前后的资格。C012的东德退出日期不能由国家统一日推出。A019所指北马其顿比赛也不能只凭“1994年入会”判定8月以后已入会。以上建议不能执行。
3. **1994年报道的范围需要收紧。** E006存档明确提及捷克、斯洛伐克和7个前苏联共和国，但没有列出7国全名，也没有据此证明北马其顿的具体入会日。不能把2018报告中的同年名单自动拼成1994年大会逐国决定。需大会名单、决定或其他FIFA原文；拼接推测单列为线索。
4. **所谓冲突必须让两边来源都可核对。** 斯洛文尼亚两种日期没有完整保存、登记双方依据，A013所引主要是年份表；暂写“存在未核实说法，待查”，不能写成已证实的真冲突。立陶宛的UEFA日期与FIFA年份差异需要进一步区分临时、正式、恢复或大会批准等含义；中国案亦须区分决定日与生效日。巴勒斯坦资料提及临时会籍，不能默认正式加入前一律无资格。
5. **交付数量与格式要修正。** 实测24个任务键涉及21个来源球队，不是批次说明中的22支；17 partial、13 conflict、2 not_found合计32，是分段建议行数，不是24项任务的状态数。如按最严重状态汇总为一任务一状态，则9 partial、13 conflict、2 not_found。A020b的match_ids为空，不能算实际比赛判断；A001的来源名称应保留German DR，不能写成German-dr。其余124项未检查应在机器可读的覆盖清单中逐项登记not_reviewed，便于下一批接续。
6. **建议场数不是已恢复场数。** 193个比赛编号中139个仅出现member建议、4个仅出现non_member建议，另50个含未决/冲突；这是按目标球队提出的建议，不等于双方资格已通过、可以恢复139场比赛。规则采纳后仍需检查双方资格和原有时间、场地等条件。

## 后续怎么做

先修正上述超出证据的推断、数量和空记录；再优先补能影响当前样本的FIFA大会原件、通告或官方历史记录，并给出原文位置和实际覆盖比赛。没有查到就保留未决，不编日期。124项未检索不代表错误，也不要求所有148项查完才允许接受局部成果；但每条要生效的规则必须先达到同一证据标准。

取得至少一项可采纳的新决定后，才转换为新规则、预演逐场去向、发布新会员版本，再统一重算第一问的表、图、权重和样本对账。旧包保留。本次没有新资格决定，重复运行现有第一问只会再次得到旧口径，不能补上证据缺口。
