## 仍阻止规则生效的问题

1. **新增FIFA主证据仍为0。** 16项来源中15项为线索，唯一FIFA主证据仍是旧2018报告。UPI及其他通讯社报道可以帮助定位大会，但没有达到用户已确认的官方历史会员依据标准。不能因多篇新闻相互接近就改称官方决定。
2. **1992年名单不能直接证明1994年逐国日期。** C015自己承认1992年被推迟申请的7国与1994年报道中未列名的7国属于跨源推断，且不能排除其他执委会决定。A025/A027的reason却写成“FIFA decision record”，现交付没有对应官方决定。应改为明确的推断建议，继续partial；取得逐国正式依据后才能执行。
3. **“批准前”不自动等于“无任何会员资格”。** A010/A013/A016等把大会接纳日期以前的比赛建议为non_member；还须排查临时、恢复或先行生效资格，不能只由正式批准日反推此前状态。可以记录线索性建议，但必须明确这层前提未证实；不能在生产规则中排除这些比赛。C006/C014中“申请推迟/拒绝，所以非会员”的断言同样应收紧，尤其C014的limitations还把一个时点扩成“此前一直”。
4. **未登记的不同说法仍被当作冲突。** A018/A020的task_status仍是conflict，理由引用未登记的更早日期说法。请保存双方依据再称证据冲突，否则改为日期未决并解释缺口；不要只修斯洛文尼亚一例。
5. **计划报道不是批准证据。** E014记载黑山“将于周四获接纳”，只能证明当时预期，不能作为大会实际通过的新增证明。需事后通过记录或官方决定。E014本批也如实列为非FIFA线索，本审核不否认它的定位价值。
