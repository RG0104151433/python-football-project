## 四、5 类重点问题逐类结论

### 1. 四舍五入膨胀
**未定位到。** 43 条「舍入差异」全部为按论文所示精度的标准四舍五入：原始高精度值与论文报告值的末位差均在半个末位单位内，最大绝对舍入幅度约 0.005（`[-61.66,62.66]` 中 −61.6553→−61.66 为 0.0047；`66.31%` 中 66.3144→66.31 为 0.0044；`312.58` 中 312.57793→312.58 为 0.0021）。未见把数值向上取整以放大结论的情形（例如 16.1181%→16.12%、0.4222%→0.42% 均为正常舍入；0.5591345→0.559135 为正常进位）。对舍入差异仅记录幅度，不作严重性指控。

### 2. best-seed cherry-pick（报告最好一轮而非平均）
**未定位到确证；但发现多个结果文件、论文采用其中一轮（非汇总），列入第六节分布。**
- 预测模型对比存在两份 `group_metrics.csv`（`rolling-prediction-4722c7b1b5f63cef35e3` 与 `rolling-prediction-41c77e3a1f9eeba865ec`）。论文表 2 / 摘要数值（0.671936 / 0.563630 / 70.01% / +0.2398）与 4722c7b1 完全一致；41c77e3a 的 M0/M3 为 0.6719443644 / 0.5636353394、accuracy 0.6999953299（70.00%）、bias +0.2401432354。两轮差异在 log loss 第 5–6 位，M1_strength 完全相同。
- 历史窗口一节报告「六个组合中最低的 main-comparison log loss 0.559135」，该值确为 6 个组合中最低（`joint-review-4888.../display_data.json` `metrics[scope=evaluation]`），且论文明确表述为「Among six tested combinations ... lowest」，属于明示的组间比较，非隐藏式取最好一轮。
- 本项仅陈述分布，不对「是否应取平均」作判断。

### 3. 配置不匹配（引用了不同实验设置的指标）
**发现两类多值并存情形，仅记录，不作严重性指控。**
- **(a) 采用参数组合**：`method.tex:64` 的「采用参数」q=0.03 / λ=0.08 / τ=1.2 / δ=0.4 / α=0.65 / ε=0.05 未在任何单个配置文件中同时出现。含 δ=0.4 的 `config/strength_handoff.json`、`strength_context_v4*.json`、`strength_context_simulation.json` 中 `jump_rate=0`；含 λ=0.08（jump_rate）的 `config/strength_pilot.json` 中 δ=0.3，`strength_repair_v5..v11.json` 中 0.08 仅为 `jump_full` 候选值。各单值均可分别定位（C17–C23），但整套「采用参数」无法定位到单一采纳配置；无法从当前输入确认是否存在单独的最终采纳参数文件。
- **(b) 年代对比的数值分布**：`outputs/tables/eras/eras-7f332ed60.../era_contrasts.csv`（样本 `sample-eafeb23c355ef5391044`，era 合计 26,055 场）中「2010s minus 1980s」的 `composition_adjustment_difference` 为 0.6689383919 / 0.5392166136、`standardized_difference` 为 0.8122266843 / 0.9419484626（两种 reference）；「2020_2024 minus 1980s」为 −0.2751607968 / 1.8294472772 / 2.1046080740 / −0.5526064319 / 2.3820537091。论文表 1 的 +0.5019 / +1.8100 pp 与 `outputs/tables/reliability/applied-*/display_data.json`（24,917 队列、不同参考与估计量）一致。即同一名称的对比在 26,055 队列与 24,917 队列下存在不同数值；论文采用后者。仅记录存在两套数值与不同分母，不推断孰对孰错。
