## 主要发现

- 前三问共同分析24,917场非中立比赛。年代、赛事和地域的平均主胜率不同，但这些差异不能直接解释为纯主场效应。
- 在同一21,413场历史预测中，共同模型相对仅背景的对数损失下降16.12%，相对仅实力下降0.42%；主胜/非主胜准确率70.01%。这些数字不是完整胜平负准确率或未来比赛成绩。
- 历史参考长度未得到普遍更优的固定年数；地区适用证据也有差别。
- 已封存2026年11月12—17日欧国联52场预测：49场主预测、3场按场地规则不外推；另附52场辅助胜平负。真实赛果尚未录入。
