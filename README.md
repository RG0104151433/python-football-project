本项目用国际足球比赛研究一个问题：**主队过去的胜率为什么不同，这些差异能否帮助判断下一场比赛？** 我们先比较年代、赛事与地区，再检查可靠性、加入赛前实力，考察历史信息长度与地区适用，最后保存真正的未来比赛预测。

**当前状态：课程约定的研究范围已收尾，正在准备论文与整组展示。** 第八问止于赛前预测，第九问只作改进方案讨论；比赛实际成绩、优化实现与俱乐部实际实验后置。正式论文、整组页面、成员复核和设备验收仍待完成。

## 主要发现

- 年代、赛事与地域的平均胜率各有差异，但平均差异不能直接解释为纯主场效应；前三问使用同一批24,917场比赛。
- 加入赛前实力后，实力承载主要预测信息，比赛背景有较小增量。1990—2024同一21,413场历史预测中，共同模型相对仅背景的对数损失下降16.12%，相对仅实力下降0.42%；二元主胜/非主胜准确率70.01%。这不是完整胜平负准确率或未来比赛成绩。
- 历史长度比较没有找到普遍更好的固定年数，保留累计默认；各地区的适用证据也有差别。
- 已封存2026年11月12—17日欧国联52场预测：49场共同模型主预测，3场特殊场地不外推；52场另附原评分器辅助胜平负。实际成绩尚未知。

研究结果均有适用边界；模型条件范围不能写成现实无条件保证。详细结论、失败与限制见各阶段说明。
