## 本地编辑与生成PDF

建议Windows安装TeX Live，编辑器选择TeXstudio，或VS Code配LaTeX Workshop。PDF可用编辑器内置预览。当前全英文骨架使用article、英文babel与fontspec，继续采用XeLaTeX；参考文献采用biblatex/biber数字引用，仅为当前骨架设置，教师专用模板与引用规则优先。主文件和四个分章的可见提示已改为英文，引用条目与正式正文仍未填写。

在仓库根目录打开终端，进入本目录后生成PDF：

```powershell
Set-Location paper
latexmk -xelatex -outdir=build main.tex
```

生成后查看`build/main.pdf`。这是TeX环境命令，与Python虚拟环境分开；初次使用先确认XeLaTeX、latexmk、biber可用。TeXstudio可打开`main.tex`并按同样的编译引擎和输出目录配置。VS Code也以`main.tex`为主文件，不逐个编译分章。

如果使用Overleaf，应上传整个paper目录，并补齐正式采用的图片，选择XeLaTeX；不要依赖未上传的仓库外文件。作者信息只填实际组员，不把AI写成人类组员。

本机工具检查的实际状态见[本次整理记录](../文档/04_整理记录/仓库整理记录_20261103.json)。本目录存在不代表已通过TeX编译或版面验收；最终成稿需另行检查。

## 快速检查与候选图生成

在仓库根目录先跑只读快速检查（不重跑模型、不写文件）：

```powershell
.\.venv\Scripts\python.exe quick_check.py
```

它核对原始快照、清洗版、研究人群、Q5 聚合、Q6/Q7 基线、Q8 预测台账，约 2 秒；`--full` 会再加跑 pytest。详细说明见[论文规划审查与开工准备](论文规划审查与开工准备_v2_20261105.md)。

生成 5 张英文候选图（PDF/PNG + manifest）：

```powershell
.\.venv\Scripts\python.exe paper\make_paper_figures.py
```

输出在`paper/figures/`；这些是候选图，不是最终论文选图。fig1研究流程仍需手工/Agent绘制。
