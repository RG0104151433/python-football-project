# 课程项目选题脑暴（小众发散版）

> 前提：保留数据科学专业管线（采集→清洗→分析建模→可视化→结论）的分析框架，暂不套用"稳妥拿分"的筛选标准，优先新意。每个选题标注数据获取方式与主要风险。
> 提醒：新意不等于高分——入围后仍需过一遍 v2 的六维度检验。

---

## A. 网络分析类（networkx，最出"惊艳可视化"）

### A1. 古典文学人物社交网络（《三国演义》/《红楼梦》）
- **数据**：维基文库全文直接下载，零风险。
- **小众角度**：按章节切分文本，构建人物同场共现网络，回答"谁才是全书真正的叙事中心"（中心性度量排序 vs 大众直觉的差距就是答辩记忆点）；可对比两本书的网络结构差异。
- **切入点**：出场频次统计 → 共现矩阵热力图 → 社区发现（魏蜀吴自动聚类，效果直观）→ 跨章节人物关系演化。
- **风险**：人物别称/字号的实体对齐需要人工建别名表，工作量集中在这里。

### A2. 全国高铁网络与枢纽城市验证
- **数据**：12306 公开车次接口（常见爬虫练习对象，需控频）或 GitHub 开源线路数据集。
- **小众角度**：把全国高铁站建成一张图，用中心性指标回答"哪个城市才是真枢纽"，与媒体口径对照。
- **切入点**：线路统计 → 全国网络图可视化 → 度/介数中心性排名 → "删除实验"（移除某枢纽后全网可达性损失多少）。
- **风险**：爬虫合规与反爬；退路是只用开源静态线路数据。

### A3. 全球机场航线网络的鲁棒性（OpenFlights）
- **数据**：openflights.org 官方公开 airports.dat / routes.dat，免爬。
- **小众角度**：全球航空网的小世界特性；枢纽失效模拟——"迪拜机场停摆，多少城市间航线中断"。
- **切入点**：网络拓扑统计 → 枢纽识别 → 节点移除的连通性破坏实验（破坏性分析很出彩）。
- **风险**：低。数据陈旧（约 2014 年快照）需在报告里说明。

## B. 时空与物理数据类（现成数据，冷门到眼前一亮）

### B1. NASA 陨石降落数据集分析
- **数据**：NASA 开放数据门户「Meteorite Landings」，约 4.5 万条，Kaggle 有镜像，免爬。
- **小众角度**：两千年来落在地球上的陨石长什么样？重量分布跨十几个数量级（对数轴）、降落地地图热力、"发现 vs 目击"的观测偏差。
- **切入点**：质量/年份分布统计 → 经纬度地图可视化 → 对数正态/幂律拟合 → 观测偏差讨论（南极陨石为何多）。
- **风险**：低。质量字段有极端值，正好练清洗。

### B2. 全球地震的统计规律验证（USGS）
- **数据**：USGS FDSN API 按条件直接查询，免费无 key。
- **小众角度**：亲手验证地震学最著名的经验规律 Gutenberg–Richter 定律（震级-频率的幂律关系）——把"统计建模"用在真物理定律上。
- **切入点**：时空分布可视化 → 震级频率双对数图与幂律拟合 → 深度分布 → 预报局限讨论。
- **风险**：低。API 分页细节需要处理。

## C. 文化与流行趋势类（答辩氛围最轻松）

### C1. Billboard Hot 100 六十年流行乐演变
- **数据**：Kaggle 历史榜单数据集（1958–2021），免爬。
- **小众角度**：冠军歌曲的"寿命"是否越来越短（榜单更迭加速）、合作曲目占比变化、歌名长度趋势。
- **切入点**：在榜时长时序 → 艺人合作网络 → 冠军歌曲特征演变 → 流媒体冲击的叙事。
- **风险**：低。纯英文场景，报告需注意表述对象。

### C2. 中文歌词意象的时代变迁
- **数据**：开源歌词爬取项目较多（注意合规）；退路是 Kaggle 14 万条英文歌词集。
- **小众角度**：按十年切片统计高频意象词（月亮/街道/下雨），看流行歌词在"唱什么"上的代际迁移；情感极性时序。
- **切入点**：分词与意象词表 → 十年代对比 → 情感打分时序 → 时代背景关联讨论。
- **风险**：中。爬虫合规 + 中文情感词典质量决定上限。

### C3. emoji 使用的时代变迁
- **数据**：Kaggle 社交媒体 emoji 使用数据集。
- **小众角度**：哪些 emoji 在退场（😂 被网友"抛弃"是真新闻）、新贵 emoji 的崛起曲线。
- **切入点**：频率时序 → 崛起/衰落 emoji 识别 → 语义漂移案例（🙏/💀 的用法变迁）。
- **风险**：中。数据源偏英文平台，中文场景要另找。

### C4. Steam 游戏生态分析
- **数据**：SteamSpy API 免 key 开放，Steam 官方 API 取评测数据；也有 Kaggle 存档。
- **小众角度**：什么游戏有人玩没人夸？价格、类型、发行年份与玩家数/好评率的关系；"差评如潮但在线人数惊人"的异常游戏个案分析。
- **切入点**：类型-价格分布 → 评测 sentiment 与玩家数回归 → 异常点分析 → 免费游戏子生态对比。
- **风险**：低。数据现成，答辩现场演示效果好。

## D. 社会经济类（应用价值叙事强）

### D1. 国际足球比赛 150 年数据与自建 Elo 评分
- **数据**：Kaggle「International football results 1872–2024」，四万多场全量比分，免爬。
- **小众角度**：主场优势到底值多少球？不调包，亲手实现 Elo 评分体系给全世界球队打分——"自建模型"比"调库跑模型"在报告里含金量高一档。
- **切入点**：主场胜率检验 → Elo 实现（几十行代码）→ 评分曲线回溯著名球队兴衰 → 用历史数据回测预测准确率。
- **风险**：低。数据极干净。

### D2. 宠物领养速度预测（PetFinder.my）
- **数据**：Kaggle 竞赛数据集，约 1.5 万条宠物档案（品种/年龄/健康/描述文本+照片），免爬。
- **小众角度**：什么样的宠物被领养得慢？"绝育/疫苗/照片数量"对领养速度的影响，指向动物福利的实在结论。
- **切入点**：领养速度分布 → 特征影响分析 → 生存分析或有序分类建模 → 描述文本情感的作用。
- **风险**：低中。有序目标变量的建模对新手稍有概念门槛。

### D3. 全球电力结构转型画像
- **数据**：Ember（ember-climate.org）与 Our World in Data（GitHub owid/energy-data）官方开放 CSV，免爬。
- **小众角度**：给各国电力结构"画像聚类"——谁在真转型、谁在原地踏步；碳强度与人均 GDP 的解耦分析。
- **切入点**：能源结构堆叠图 → 各国时序 → KMeans 国家聚类 → 转型速度排名。
- **风险**：低。数据干净，报告自带政策讨论深度。

### D4. B 站视频爆款因素分析
- **数据**：B 站公开视频信息接口（控频合规）或 Kaggle/开源存档数据集。
- **小众角度**：标题长度、发布时段、分区、时长与播放/点赞率的定量关系；"标题党有用吗"这类问题天然有讨论度。
- **切入点**：分区分布 → 发布时段热力 → 爆款定义与对比 → 互动率回归。
- **风险**：中。爬虫合规；建议以现成存档数据为主。
