# Python 课程项目选题推荐（面向期末课程设计）

> 课程：《Programming with Python, Fall 2026》课程项目
> 硬性约束回顾：组内 ≤4 人；代码 ≥100 行、至少 2 个数据分析/AI 库；报告按五节模板写；11 月 13 日 23:59 截止；第 9–11 周课堂答辩 10 分钟。
> 评分关键点：递进式分析结构、可复现实验、可视化质量、创新性、结论有基线对照。

## 选题一：共享单车租赁需求分析与预测（UCI Bike Sharing）

**一句话定位**：用两年小时级租车记录回答"什么因素在驱动租车需求、能否按时预测需求量"。

### 1) 数据来源及获取方式
- UCI Machine Learning Repository 的 **Bike Sharing Dataset**（美国华盛顿特区 Capital Bikeshare，2011–2012），直接下载 CSV，无需爬虫。
- Kaggle 有同名镜像，备用。UCI 页面附带字段说明文档，写报告的 Method 节时可直接引用。

### 2) 数据规模与可靠性
- 小时级表约 **17379 条 × 17 字段**（日期、季节、天气、温度、湿度、风速、时段、casual/registered/cnt 租用量），另有天级表 731 条。
- 官方整理过的数据，**无缺失值**，质量在候选数据集里最高。
- 风险点两处：极端天气日（飓风、暴雪）样本极少；风速字段有大量 0 值（疑似缺测填 0）。报告里主动说明即可变成加分项。

### 3) 问题意识与递进式分析
问题意识明确，递进路径是五个选题里最天然的：
- **基础统计**：按小时/星期/季节/年份的租用量分布；
- **可视化**：星期×小时热力图（通勤双峰一眼可见）、天气-租用量箱线图、温度-租用量散点；
- **建模预测**：按时间划分训练/测试集 → 线性回归基线 → 随机森林 → 梯度提升，逐级对比。

### 4) 清洗与分析难点及方法
- 类别变量（季节、天气、星期）独热编码；
- cnt 与温湿度是非线性关系 → 特征工程（小时分时段、工作日×小时交叉特征），这是主要创新空间；
- **最大坑**：时间序列不能随机打乱划分数据集，必须按时间切分。把这一点讲清楚本身就是报告亮点。
- 工具链：pandas + seaborn + scikit-learn，全程无冷门依赖。

### 5) 结论可靠性与可验证性
- 有天然基线：历史均值、上一小时/上周同一小时（persistence）；
- 指标用 RMSE / MAE / MAPE，模型逐级对比，结论谁高谁低一目了然；
- 可加时间序列交叉验证与超参数敏感性分析，可复现性极好。

### 6) 实际意义与应用价值
共享单车调度、运维车辆再平衡是业界真实运营问题，答辩时"解决什么、给谁用"一句话讲清；可视化成果也适合放进 PPT 当主图。

## 选题二：城市空气质量分析与 PM2.5 浓度预测（UCI Beijing PM2.5 / PRSA）

**一句话定位**：分析气象条件对污染浓度的影响并做次日预测，是与物理/大气方向专业背景最贴合的选题。

### 1) 数据来源及获取方式
- UCI 的 **Beijing PM2.5 Data**（2010–2014，含气象要素）与 **Beijing Multi-Site Air-Quality Data**（2013–2017，12 站点）两套，Kaggle 均有镜像，直接下载。

### 2) 数据规模与可靠性
- 两套合计数万条小时级记录，字段含 PM2.5、温度、湿度、风速、气压、露点。
- 风险：早期 PM2.5 缺测较多，且污染事件期缺失更集中（缺失机制非随机）。清洗时必须写明缺失处理策略及其偏差，这是难点也是得分点。

### 3) 问题意识与递进式分析
- **基础统计**：污染水平的月度/季节分布、超标天数统计；
- **可视化**：风玫瑰图、季节-浓度箱线图、多站点对比热力图；
- **建模预测**：加入滞后特征（前 1/24 小时浓度）后做回归预测。
- 物理衔接点：可加入大气扩散、湿沉降机制的定性讨论，作为"结合本专业"的创新点。

### 4) 清洗与分析难点及方法
- 缺失值处理：删除 vs 插补的偏差讨论；
- 浓度序列自相关强，划分数据集同样要按时间；
- 滞后特征、滑动均值特征构造。工具链同样是 pandas + seaborn + scikit-learn。

### 5) 结论可靠性与可验证性
- 明确判据：**持续性预测基线（今天=明天）在空气质量上相当强**，模型必须击败它才有说服力；
- 两套数据集时段、站点不同，可互相印证结论，这是其他选题没有的验证手段。

### 6) 实际意义与应用价值
环境健康预警、政策效果评估（如煤改气前后对比）社会价值高；若小组想强调"分析应用于本专业领域"这条课程要求，此选题契合度第一。

## 选题三：垃圾短信识别与文本表示方法对比（UCI SMS Spam Collection）

**一句话定位**：对比不同文本表示（词袋 / TF-IDF / 字符 n-gram）与分类器在垃圾短信识别上的表现，天然是"对比实验"结构。

### 1) 数据来源及获取方式
- UCI **SMS Spam Collection**，5574 条英文短信（文本 + ham/spam 标签），TSV 直接下载；
- 可选加分项：用 requests + BeautifulSoup 演示一个简单爬虫抓取短信样本，呼应课程对爬虫途径的开放态度（非必需）。

### 2) 数据规模与可靠性
- 5574 条、两列，无缺失；spam 占比约 13.4%，存在类别不平衡。
- 风险：规模偏小；英文语料（与国内生活场景稍远）；垃圾词会随时间漂移，对新样本泛化有不确定性。

### 3) 问题意识与递进式分析
- **基础统计**：词频 Top-N、短信长度分布、spam/ham 高频词差异；
- **可视化**：词云、长度分布直方图；
- **建模**：朴素贝叶斯 → 逻辑回归 → 线性 SVM，叠加三种文本表示形成对比矩阵，实验结构工整。

### 4) 清洗与分析难点及方法
- 文本预处理（大小写、标点、停用词）；
- 稀疏特征下过拟合控制；
- 创新点：字符级 n-gram 能抓住故意变形词（"freee"、"WINNER"），对比效果通常有惊喜。

### 5) 结论可靠性与可验证性
- 分层 k 折交叉验证；基线为关键词规则分类器和多数类；
- 指标用 Precision / Recall / F1（不平衡数据不能只看准确率）；标准数据集结果稳定，可复现性好。

### 6) 实际意义与应用价值
反垃圾过滤是经典真实业务；工作量在五个选题里最轻，适合时间紧的小组；缺点是英文短信离国内场景有距离，答辩时需要解释动机。

## 选题四：电影推荐系统对比（MovieLens 100K）

**一句话定位**：在同一数据上对比流行度推荐、基于物品的协同过滤、矩阵分解三种算法。

### 1) 数据来源及获取方式
- GroupLens 官网 **MovieLens 100K**：10 万条评分（943 用户 × 1682 电影），附用户与电影元数据，直接下载。

### 2) 数据规模与可靠性
- 10 万条评分，是推荐系统研究的标准基准数据集，字段规范。
- 风险：评分矩阵极稀疏（约 6.3%），冷门电影评分极少，评估指标对小样本敏感，需在实验设计上控制。

### 3) 问题意识与递进式分析
- **基础统计**：评分分布、用户活跃度、电影流行度长尾曲线；
- **可视化**：评分长尾图、类型-年代分布；
- **建模**：流行度推荐 → ItemCF → SVD 矩阵分解，逐级对比 RMSE 与 Top-N 指标。

### 4) 清洗与分析难点及方法
- 稀疏矩阵存储与相似度计算效率；
- 评估协议要想清楚：预测评分（RMSE）与 Top-N 推荐（Precision@K / NDCG）是两套指标，混用是常见扣分点；
- 创新空间：冷启动讨论、按时间划分的用户留出实验。

### 5) 结论可靠性与可验证性
- **独有优势**：官方提供固定切分（u1–u5），结果可与公开文献直接对照——结论可验证性最强的一个选题；
- 每个算法都有明确基线可打。

### 6) 实际意义与应用价值
电商与流媒体的核心业务；答辩演示效果好（现场给某用户生成 Top-N 列表并解释推荐理由）。缺点是推荐系统概念对新手略抽象，实现工作量是五个选题里最大的。

## 选题五：葡萄酒质量分析与预测（UCI Wine Quality）

**一句话定位**：用理化指标预测感官评分，最容易上手，但也是撞题率最高的选题。

### 1) 数据来源及获取方式
- UCI **Wine Quality**（葡萄牙 Vinho Verde：红 1599 + 白 4898 条，11 个理化指标 + 评分），直接下载。

### 2) 数据规模与可靠性
- 约 6500 条，无缺失，字段含义清楚（教学友好）。
- 风险：类别严重集中在 5–6 分（极端好/差酒极少）；评分是多位评委的主观均值，噪声不可避免。

### 3) 问题意识与递进式分析
- **基础统计**：各指标分布、与质量的相关系数排序；
- **可视化**：相关性热力图、按质量分组的箱线图；
- **建模**：逻辑回归 → 随机森林 → SVM（分类视角）或线性回归 → 集成模型（回归视角）。

### 4) 清洗与分析难点及方法
- 类别不平衡处理（类别权重、重采样）；
- 特征共线性（free/total sulfur dioxide 高度相关）；
- 难度整体最低，适合编程经验较少的小组。

### 5) 结论可靠性与可验证性
- k 折交叉验证 + 多数类/简单逻辑回归基线，F1/AUC 对比，实验规范容易达标；
- 但预测上限低：理化指标只能解释部分感官评分。诚实讨论这个上限反而是 Discussion 节的好素材。

### 6) 实际意义与应用价值
酿酒品控辅助，意义成立；但该数据集被全网教程做烂，**创新性容易被压分**，要拿高分必须自己加差异点（如回归与分类双视角对比、异常酒样分析）。

## 最终推荐

**首选：选题一（共享单车需求预测）。**

理由：
1. 数据零风险，清洗工作量小，时间预算可控，适合 4 周内完成；
2. "统计 → 可视化 → 预测"的递进结构天然成型，报告五节模板每一节都有实料可写；
3. 有明确的可击败基线（历史均值 / persistence），结论可靠可验证，正好满足"实验结果可复现"的硬要求；
4. 可视化表现力强（通勤双峰热力图本身就是答辩主图），应用故事好讲；
5. 创新点集中且可操作：时间划分方法论讨论 + 交叉特征工程 + 三模型梯度对比，不用追求复杂模型就能体现创新性。

**备选：选题二（空气质量）。** 若小组希望在报告里强调"数据分析应用于本专业领域"（物理/大气方向），选它更贴题，且双数据集互证在论证上更强；代价是要花精力处理非随机缺失。

**执行建议（倒排）**：第 1 周完成数据获取 + EDA 与可视化；第 2 周完成基线与主模型；第 3 周做对比实验、超参分析与图表定稿；第 4 周写报告、准备 10 分钟答辩排练。所有分析脚本保留运行入口，保证"一键复现"。
