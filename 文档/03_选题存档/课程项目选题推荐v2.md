# Python 课程项目选题推荐 v2（基于三点反馈的修订版）

> 反馈要点：①共享单车选题热度过高，需重新评估；②小组专业为**数据科学与大数据技术**，专业知识尚不深入，要求自然融入专业内容；③数据来源要突破 UCI，探索更多样化的渠道。
> 修订逻辑：专业改为数据科学后，选题的价值标准从"领域贴合"转为**"能否完整展示数据采集→清洗→分析建模→可视化→结论"的专业管线**；数据采集能力（API / 爬虫）本身成为差异化亮点。

---

## 反馈一：共享单车热度分析——是否降级？

**结论：热度本身不足以一票否决，但足以把它从首选降为保底选项。**

理由分三层：

1. **不支持一票否决的部分**：课程评分看的是报告质量、可复现性、分析深度与答辩表现，不设"选题新颖度"的一票门槛。成熟选题文献多、路径清晰、踩坑资料全，执行风险最低。
2. **支持降级的部分**：
   - "体现一定创新性"是说明书里的明示要求。评委在答辩周要听几十个小组，共享单车、葡萄酒质量这类"经典题"撞题率高，同等质量下边际印象分会受损——创新性上有一个看不见的天花板；
   - 对数据科学专业来说，共享单车的相对优势（时间划分方法论、特征工程）在其他选题上同样能展示，而它在"数据采集"环节几乎没有发挥空间——这是本专业最核心的差异化能力之一；
   - 全网教程极多，报告容易写得"像教程复述"，反而显得没有独立思考。
3. **保留价值**：若临近截止发现进度落后，它是最好的安全垫——数据零风险，两周可以做完。

## 调整后主题排序（对比列表）

### 第 1 位：数据科学岗位薪资与技能需求分析

- **推荐理由**：研究对象就是本专业的就业市场，问题意识与专业契合度天然拉满；全链路（采集→清洗→分析→建模）每一环都有实料；答辩时有代入感，评委易共鸣。难度完全匹配现状——只需 pandas + scikit-learn 经典方法。
- **数据来源**：Kaggle「Data Science Job Salaries」（约 670 条，职位/经验/远程/薪资，2020–2023）打底；和鲸/天池的国内招聘数据集补充中文样本；进阶组可用 requests 爬取招聘网站岗位页扩容（控制频率、只采公开字段）。多源合并本身就是一次真实的数据工程练习。
- **适合水平的切入点**（由浅入深）：
  1. 基础统计：岗位分布、经验层级 × 薪资中位数、远程 vs 坐班对比；
  2. 可视化：薪资箱线图、技能词频 Top-N 与共现矩阵（中文数据配 jieba 分词）；
  3. 建模：对数薪资回归（线性回归 → 随机森林），特征重要性分析回答"哪些因素最影响薪资"；
  4. 进阶创新：KMeans 岗位聚类画像；技能组合与薪资溢价分析。
- **数据科学专业内容融入点**：数据采集（API/爬虫）、多源数据清洗与对齐（去重、薪资单位归一、类别编码）、EDA 方法论、经典回归与无监督学习——完整覆盖课程目标。

### 第 2 位：电影评分与票房影响因素分析（IMDb + TMDb）

- **推荐理由**：数据规模大且真实，"什么决定一部电影的口碑/票房"问题意识直观；IMDb 官方 Bulk 数据免爬虫就能拿到千万级记录，再用 TMDb API 补预算字段，采集环节有层次；可视化素材极丰富，答辩主图好选。
- **数据来源**：IMDb Datasets（title.basics / title.ratings 等 TSV，官方开放下载）；TMDb API（免费注册 key，取预算/票房/类型）；Kaggle 镜像备用。
- **适合水平的切入点**：
  1. 基础统计：类型、年代、语言、片长分布，评分长尾曲线；
  2. 清洗重点：多表 join、缺失预算处理、小样本电影过滤——这是主要工作量，也是报告 Method 节的干货；
  3. 可视化：类型-评分热力图、年代趋势；
  4. 建模：评分回归（片长/类型/年份/投票数）→ "是否高分"分类，逻辑回归与随机森林对比，k 折交叉验证。
- **数据科学专业内容融入点**：大规模数据的抽取与合并（pandas 分块读取）、缺失值机制分析、特征工程、回归与分类双视角评估。
- **风险**：票房字段缺失集中（大片才披露），需在报告里诚实讨论样本偏差。

### 第 3 位：中文电商/外卖评论情感分析

- **推荐理由**：中文 NLP 比英文短信更贴国内场景；"词袋/TF-IDF/字符 n-gram × 朴素贝叶斯/逻辑回归/SVM"的对比矩阵实验结构工整，最适合展示规范的对比实验方法；天池现成数据，也可爬取近期评论补充时效性。
- **数据来源**：天池/和鲸中文外卖评论数据集（约 2 万条带标签）；Kaggle 中文电商评论；可选爬虫采集评论页。
- **适合水平的切入点**：
  1. 基础统计：好评/差评长度分布、高频词差异（jieba + 停用词表）；
  2. 可视化：词云、对比条形图；
  3. 建模：三种文本表示 × 三分类器的网格对比，分层 k 折交叉验证，Precision/Recall/F1 报告（不平衡数据不能只看准确率）；
  4. 进阶创新：差评的 LDA 主题模型，把"用户在抱怨什么"分类呈现。
- **数据科学专业内容融入点**：文本预处理管线、特征表示对比、不平衡数据处理、主题模型入门。
- **风险**：分词与停用词质量决定效果上限；情感极性标注噪声需抽样人工复核。

### 第 4 位：城市空气质量与气象条件关系分析

- **推荐理由**：数据权威、管线完整、时间序列分析是数据科学的必备技能训练；持续性基线（今天=明天）提供明确可验证的判据。专业契合度上不再是"物理专属"，但作为环境数据科学案例依然成立。
- **数据来源**：UCI Beijing PM2.5 / PRSA（保留）、中国气象数据网、Open-Meteo API（免费取气象要素）、国家统计局。
- **适合水平的切入点**：污染水平季节统计 → 风玫瑰图/热力图 → 滞后特征回归预测 → 与持续性基线对比。
- **融入点**：缺失机制分析、时间序列划分、滞后特征工程。
- **风险**：缺失值非随机，清洗需花心思。

### 第 5 位：共享单车需求预测（原首选，降为保底）

- **推荐理由**：数据质量最优、路径最成熟、执行风险最低；热度高是它的唯一硬伤——创新性天花板受限，且对数据科学专业没有采集环节的展示空间。**适用场景：进度落后、时间紧张时的安全选择**；若坚持选它，必须靠特征工程深度（分时段交叉特征、多模型梯度对比、时间划分方法论讨论）拉开与"教程复述"的差距。

> 原 v1 的 MovieLens 推荐系统与葡萄酒质量两个选题移出前五：前者评估协议（RMSE vs Precision@K）对新手偏抽象，后者撞题率最高、创新空间最小。小组若对推荐系统有特别兴趣，MovieLens 仍可作为替代项。

## 最终建议

**首选：数据科学岗位薪资与技能需求分析。** 它同时回应了三点反馈——热度低（几乎不会撞题）、专业契合度最高（数据科学专业分析数据科学就业，且能完整展示采集→清洗→建模→可视化的专业管线）、数据来源覆盖 Kaggle + 和鲸 + 可选爬虫的多元组合。难度全部落在经典方法内，不需要深度学习基础。

**次选：电影评分与票房分析。** 数据规模感和采集层次更好，适合想在"大数据"三个字上多做文章的小组。

**保底：共享单车。** 进度失控时启用。

**通用执行提示**：
- 管线脚本分离：`01_collect / 02_clean / 03_eda / 04_model` 四个阶段各一个脚本，保证一键复现——这既是硬要求，也是数据科学专业的规范训练；
- 全程只用 pandas + matplotlib/seaborn + scikit-learn（已满足"至少两个库"），不要碰深度学习，把时间花在清洗严谨性和图表质量上；
- 报告 Discussion 节写清数据局限（样本偏差、缺失机制），评委吃这一套。
