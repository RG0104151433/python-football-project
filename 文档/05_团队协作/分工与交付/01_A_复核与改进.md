# A 的任务：检查能否重跑、处理是否合理

**新增第二问任务：** 按[本地复现与交付要求](../../../研究/02_赛事类型差异/本地运行与复现.md)实际运行主程序、独立核查、手算年代/窗口；两问须同一24,917个比赛ID。本次全套参考106项测试通过，A保留自己的实际输出，不照抄AI检查当本人复现。正式推断理论仍由共同阶段验收。

你不需要重新写一套程序。你的工作是独立运行、挑出具体问题、提出改进建议，最后交一份能复查的记录。

## 第一步：在自己的电脑运行

先按[上手指南](../../02_环境配置/克隆仓库后的快速上手.md)配置。依次运行快照验证、审计、清洗和结果验证，再运行测试；进入研究前先按[数据再次确认](../../../研究/00_数据再次确认/README.md)构建/验证当前会员包。

保存一份运行小结，至少写：自己的 Python 版本、运行日期、各命令是否成功、清洗版本、输入/纳入/窗口外/隔离数量、报告所在位置。遇到报错保留完整输出，不只截最后一行。

当前同一清洗版本参考数量为 49,945 / 48,102 / 1,803 / 40；当前全仓库测试参考为106项通过（92/85/48/34项是旧阶段记录）。要记录你自己实际看到的结果；若不同，先报告差异，不为了对齐数字手改文件。

交付：`A_运行复核_日期.md`。组长确认这一步后，再扩大检查。

## 第二步：检查几条关键规则

先读 README，再从 src/clean.py 看入口；不懂的函数可以问 AI，但最终要自己说清楚下面几件事：

1. 原始 CSV 有没有被覆盖？看 snapshot --verify 结果及原始文件指纹，不以“我没看到变化”作依据。
2. FALSE 是否真的表示非中立？看测试和具体结果，不能把所有非空文字都当成 True。
3. 加时后的比分和点球胜者有没有混到一起？找世界杯决赛案例核对，平局进入点球后主表仍可能是 draw。
4. 同日同队的两条记录如何处理？看候选表、隔离表和逐行去向，不能看到候选就宣称重复已证实。
5. 2025 年以后的比赛是否仅被排除出本轮分析，仍留在原始文件中？
6. 输入数能否按报告分成纳入、窗口外和隔离？若有其他状态也要算进去，不能漏记录。

不要求你人工核对全部比赛。已有测试不等于你的复核，你需要挑几个例子说明自己检查了什么。

交付：`A_规则检查_日期.md`，逐项写“通过/发现问题/还没看懂”，附文件、原始记录位置或测试名称。不会的内容如实列出，核心算法最终由组长把关。

## 第三步：把问题说具体

每条问题用下面的格式，不只写“建议优化”：

```text
问题：
在哪个文件/哪条记录：
我做了什么操作：
实际出现什么：
按方案应该怎样：
我的建议与影响：
是否必须先修，还是可以稍后处理：
```

优先处理会改变数据、丢记录、导致无法重跑的问题；界面、注释和排版建议单独列。不要因为主场结论不显著而建议改变样本或参数。组长确认后再改代码或方案，不边改边用新规则宣布原方案有错。

## 第四步：顺手检查说明是否好用

按文档操作时，记下缺少的步骤、难懂的词、失效链接和路径。后续图表出来后，再核对图中样本量、报告数字是否与结果文件一致。

如需帮助 B，先检查其两场小样，给一次明确反馈；不要默认替 B 做完剩下的工作。

## 怎样算完成

先清洗验证，再运行会员包构建/验证，最后按[年代分析复现清单](../../../研究/01_年代变化/本地运行与复现.md)复现当前接入版：核对26,055=纳入24,917+排除1,138、当前范围待定0及117场全部纳入，手算一个年代的原始与调整比例、重复运行并验证哈希，另交A_年代分析复现_日期.md。只有专门复现旧基线时才以26,055场为输出目标，不把旧版检查当作新版已验收。不会的推断理论如实列出，不用“AI 审核通过”替代本人检查。

你能在电脑上重跑，交出运行记录和规则检查，问题有具体证据；组长能据此复查。没有发现错误也可以，但要写清检查范围，不能只交一句“AI 审核通过”。
