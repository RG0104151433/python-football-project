## Purpose and principles

CCFA-Skills separates research framing, literature, experiments, writing, review and visual communication. Research questions come before tools. Claims should retain traceable sources and numerical evidence. Missing facts remain missing. Review and rewriting are separate activities. Exemplars inform narrative and evidence organization without copying their sentences or imposing one template on every study.

Humanization aims for direct academic prose while retaining real limitations and disclosures. Numerical graphics should be reproducible; architecture illustrations can begin with visual exploration and later be rebuilt as editable SVG, PDF or presentation objects.

## Eighteen roles

- `ccf-common`: task routing, evidence and privacy rules.
- `ccf-pipeline-orchestrator`: goals, stages and next steps.
- `ccf-project-scaffolder`: manuscript and evidence workspace.
- `ccf-idea-reviewer`: concept value and mechanism, not default experimental assessment.
- `ccf-idea-optimizer`: develop a question, insight, method and evidence route.
- `ccf-literature-searcher`: related work, datasets and public baselines.
- `ccf-literature-monitor`: track subsequent work.
- `ccf-experiment-designer`: comparisons, ablations, robustness and result structures.
- `ccf-research-engineer`: implementation, reproduction and diagnostics.
- `ccf-integrity-auditor`: claims, numbers, terms, figures and citations.
- `ccf-paper-reviewer`: independent scientific assessment and revision comparison.
- `ccf-paper-writer`: drafting, revision, polishing and compression.
- `ccf-humanization`: natural, precise academic expression.
- `ccf-rebuttal-writer`: response letters and revision records.
- `ccf-visual-composer`: scientific figures, tables, diagrams and editable visuals.
- `ccf-submission-checker`: format, page limits, anonymity, PDF and supplements.
- `ccf-paper-to-exemplar`: extract reusable writing principles from supplied papers.
- `ccf-skill-forger`: maintain the skill family and resolve conflicts.

## Configuration and workflow

The source describes eight presets: lightweight, balanced, deep, focused writing, submission review, idea exploration, visual refinement and autonomous research. They control additional retrieval, independent review and figure work, affecting time/token cost. Explicitly requested work and necessary verification still apply in a lightweight mode.

The separate results-pending drafting switch is disabled in all presets. When deliberately enabled it permits clearly marked conditional analysis and placeholders; it does not authorize invented measurements or running an experiment merely to fill them. Opening the configuration interface does not itself start model work.

The workflow progresses from idea assessment/development through evidence retrieval, experiment design, engineering, writing, integrity review and submission checks. Reviewers judge; writers revise. Visual composition does not select favorable data or fabricate numbers.

## Visual and writing examples

The upstream README presents DynTrace architecture/poster examples and numerical dashboards, heatmaps, volcano, grouped-bar, slope and radial charts. Image concepts are not automatically editable vectors. The source distinguishes manuscript readiness from improvement relative to a prior version.

The pinned update also describes continuity across long conversations, independent agent handoffs, research iteration, user preferences, paragraph-level narrative repair, domain-specific review and readable figures. Nine named visual templates cover mechanism overviews, benchmarks, ablation interactions, scaling, representation diagnostics, biological data, paired effects, calibration and sensitivity dynamics.

Some upstream assets and reference files are absent from this selected local excerpt. Consult the original source and manifest rather than treating missing optional examples as project research failures. This project used the material to examine writing standards, not to certify CCF-A quality, install the full family, upload the paper or fabricate experimental outcomes.
