06 / STRENGTH DEFINITION

A changing estimate of ability—not a world rank.

The model uses earlier results to locate a team on a shared performance scale. A higher estimate means a stronger expected performance against the same opponent, with venue held fixed.

Zero is a reference, not “no ability”; these values are not Elo or FIFA points. Whiskers show ±1 marginal SD, not a guaranteed result.

08 / QUESTION 6: MEMORY

How much history should a prediction remember?

Too little history discards evidence; too much may retain an earlier team. We tested both rating memory and the outcome-model window.

Ordered by probability quality (lower log loss), not by a claim of statistical superiority. The 3D cards are visual styling; the data have two window choices and one score. Bar heights use an enlarged loss scale above 0.558, not zero. Main comparison: 9,727 identical matches, 2010–2024.

10 / THE OUTCOME CHECK

Judge the forecast using a rule fixed in advance.

Final 90-minute scores, including stoppage time. Draw = non-home win for the binary model. Ties in three-way probabilities use Home → Draw → Away. Withheld main forecasts and unverified/pending results are excluded from that denominator.

A probability range is not a score interval or a correctness test. The sealed forecast values are never edited by result import. Storage is local to this browser; keep an exported CSV backup.
